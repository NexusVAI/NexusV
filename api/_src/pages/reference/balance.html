API 参考
账户与模型

查询余额与用量

GET
/v1/balance

返回账户的可用余额、当前密钥的用量上限，以及当前密钥最近的调用记录与每次的实际扣费。它会校验密钥，所以也是检查密钥是否有效的推荐方式。

这个端点不计费，也不计入推理接口的 RPM 与 TPM，但每个账户每分钟最多调用 30 次。使用团队密钥时返回团队余额。更多用法见查询余额与用量。

任何持有密钥的人都能查询账户余额。不要把密钥交给不应看到余额的人。
请求头
Authorization: string必填

Bearer cancri_sk_…，也可以改用 x-api-key。

查询参数
limit: integer可选默认 20

返回最近调用记录的条数，取值为 0–100 的整数。传 0 时只返回余额，不返回调用记录。超出范围或不是整数时返回 400 invalid_limit。

返回
object: "balance"
currency: "CNY"
balance: number

可用余额，单位为元。个人密钥返回账户的 API 额度余额（该账户下所有个人密钥共用）；团队密钥返回所属团队的余额。

debt: number

欠费金额，单位为元，通常为 0。

key_limits: object

当前密钥在控制台设置的累计上限与用量。没有设置的上限返回 null；没有上限时，已用量最多有约 60 秒延迟。
max_total_tokens: integer or null

累计 token 上限。

used_total_tokens: integer

已用 token 数。

remaining_total_tokens: integer or null

剩余 token 数，没有上限时为 null。

max_request_count: integer or null

累计请求数上限。

used_request_count: integer

已用请求数。

remaining_request_count: integer or null

剩余请求数，没有上限时为 null。

recent_usage: object

{"object": "list", "data": […]}：当前密钥最近的调用记录，按时间倒序，只包含这一把密钥的记录。
data 中每一项的字段：
model: string

调用的模型 ID。

prompt_tokens: integer

输入 token 数。

completion_tokens: integer

输出 token 数。

status_code: integer

该次调用的 HTTP 状态码。

cost: number or null

该次调用的实际扣费，单位为元，保留 6 位小数，已计入缓存折扣。免费模型与缓存命中为 0；请求仍在结算中时为 null，求和时不要把它当作 0。

created_at: string

调用时间，ISO 8601（UTC）。

响应带 Cache-Control: no-store, private。

错误
invalid_limit: 400

limit 不是 0–100 的整数。

invalid_api_key: 401

密钥缺失、无效或已撤销。

account_suspended: 403

账户已被限制使用。

rate_limit_exceeded: 429

同一账户每分钟查询超过 30 次，带 Retry-After: 60。

service_unavailable: 503

认证或余额服务暂时不可用，可以重试。

curl "https://cn.nexusvai.xyz/v1/balance?limit=20" \
  -H "Authorization: Bearer $CANCRI_API_KEY"
import os
import requests

resp = requests.get(
    "https://cn.nexusvai.xyz/v1/balance",
    params={"limit": 20},
    headers={"Authorization": f"Bearer {os.environ['CANCRI_API_KEY']}"},
    timeout=30,
)
resp.raise_for_status()
data = resp.json()
print(data["balance"], data["currency"])
const resp = await fetch("https://cn.nexusvai.xyz/v1/balance?limit=20", {
  headers: { Authorization: `Bearer ${process.env.CANCRI_API_KEY}` },
});
if (!resp.ok) throw new Error(`HTTP ${resp.status}`);
const data = await resp.json();
console.log(data.balance, data.currency);
