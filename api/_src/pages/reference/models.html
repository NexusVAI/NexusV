API 参考
账户与模型

列出模型

GET
/v1/models

列出当前可以通过 API 调用的模型。返回的 id 就是请求中 model 的取值，三个文本生成端点共用这一份列表。模型的价格、上下文长度与能力见模型目录。

这个端点不校验密钥、不计费。列表只包含 API 可用的文本模型；图像与视频模型、只在桌面端开放的模型不在其中。

GET /v1/models 能返回结果，不代表推理接口可用：API 维护期间（503 api_paused）它仍可读取。要确认密钥有效，请调用 GET /v1/balance。
请求头
Authorization: string可选

可以照常携带，网关不会校验。

anthropic-version: string可选

带上这个请求头（或 User-Agent 中含 anthropic / claude）时返回 Anthropic 格式。Anthropic SDK 与 Claude Code 会自动带上。

返回
object: "list"
data: array of object

可用的模型，一次全部返回，没有分页。
id: string

模型 ID，大小写与连字符必须原样使用。

object: "model"
created: integer

固定值，不代表模型的发布或上架时间。

owned_by: string

通常为 cancri。不要用它判断模型厂商。

max_output_tokens: integer

NexusVAI 扩展字段：该模型单次输出的上限。请求没有设置输出上限时，网关按这个值补上 max_tokens。目录中没有这个数时省略。

返回（Anthropic 格式）
data: array of object

每项包含 type: "model"、id、display_name（与 id 相同）与 created_at（ISO 8601 时间，同样是固定值）。不包含 max_output_tokens。

has_more: boolean

始终为 false。分页参数（limit、before_id、after_id）会被忽略。

first_id / last_id: string or null

列表中第一个与最后一个模型的 ID。

目录中的模型会上下架，列表可能要几分钟后才反映变化。GET /v1/models/{id} 不存在，会返回 404。

curl https://cn.nexusvai.xyz/v1/models
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://cn.nexusvai.xyz/v1",
    api_key=os.environ["CANCRI_API_KEY"],
)

for model in client.models.list():
    print(model.id)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://cn.nexusvai.xyz/v1",
  apiKey: process.env.CANCRI_API_KEY,
});

for await (const model of client.models.list()) {
  console.log(model.id);
}
