建立实时语音会话

WS
wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions

用 GET 发起 WebSocket 升级，建立一个与 gpt-live-1 的全双工语音会话：你持续发送麦克风音频，模型边听边说，并返回双向转写。事件格式与 OpenAI Live 协议一致。指南见 GPT-Live 概览。

认证、账户状态与限流都在握手阶段检查，未通过时直接返回 HTTP 错误，WebSocket 不会建立。握手成功后，在 20 秒内发送第一条事件 session.start。

实时语音只能连接 chat.nexusvai.xyz。cn.nexusvai.xyz 不支持 WebSocket，连接会返回 426 websocket_required。不支持 WebRTC：用 POST 创建会话会返回 400 live_webrtc_not_supported。
握手请求头
Authorization: string可选

Bearer cancri_sk_…，服务端程序推荐使用；也可以用 x-api-key。三种方式至少提供一种。

Sec-WebSocket-Protocol: string可选

浏览器不能自定义 WebSocket 请求头，可以把密钥放在子协议 openai-insecure-api-key.cancri_sk_…（别名 cancri-key.cancri_sk_…）中，并同时附带一个普通子协议（例如 cancri-live）。服务端会选用普通子协议，密钥不会出现在响应头中。

密钥设置了模型白名单时，白名单必须包含 gpt-live-1；绑定了模型分组的密钥不能用于实时语音。不要把正式密钥写进公开网页，浏览器直连只适合本地调试。

第一条事件：session.start

必须是第一条事件且只能发送一次。未列出的字段会被拒绝（unknown_parameter），不会被忽略。

type: "session.start"必填
session: object必填

会话设置。
model: "gpt-live-1"可选

只能是 gpt-live-1，可以省略。

instructions: string可选

语音层的系统提示（语气、人设、语言等），最多 64,000 个字符。省略时使用默认指令；填写后按原文使用。

audio: object可选

format：{"type": "audio/pcm", "rate": 24000}（默认）或 rate: 16000；电话场景可用 audio/pcmu / audio/pcma，rate: 8000。PCM 为 16 位小端、单声道。output.voice：音色名，例如 marin。

input: array of object可选

预置的对话历史，最多 128 条，role 为 developer、user 或 assistant。

delegation: object可选

后端设置：省略为官方 GPT-6-Luna 后端；responses.model 填站内模型 ID 时由该模型回答；type: "client" 只使用语音层。acknowledgement_delay_ms 取 0–10000。详见会话与后端模式。

store: false可选

只能为 false 或省略。

triggers: array可选

只能是空数组或省略（不支持 Decisions）。

event_id: string可选

最多 128 个字符。出错时会在 error.client_event_id 中原样带回，所有客户端事件都可以带。

客户端事件

所有事件都是 JSON 文本帧，不接受二进制帧。会话开始前发送的事件会排队，最多 200 条。

session.input_audio.append

持续推送麦克风音频，audio 为 base64，单条最多 2,000,000 个字符，建议每 20–100 ms 发送一块。静音也要发送。

session.input_audio.mute / .unmute

暂停或恢复收音。

session.update · response.item.create · response.create

仅官方后端模式：修改后端设置、交回函数结果、让后端继续生成。

session.commentary.append 等

session.commentary.append、session.thinking.append、session.instructions.append：只使用语音层时，由你的程序向语音层提供内容。

session.close

结束会话。服务端返回 session.closed（带最终计费秒数）后断开。

服务端事件
session.started

会话已开始，之后开始持续发送音频。

session.output_audio.delta

回复音频（base64，格式同 audio.format）。

session.input_transcript.delta / session.output_transcript.delta

用户语音与回复的转写增量。

session.usage.updated / session.closed

usage.seconds 为累计计费秒数（不要相加）；session.closed 另带结束原因 reason。

cancri.*

NexusVAI 扩展事件，用于显示费用与状态：cancri.session.created、cancri.billing.updated、cancri.session.closing、cancri.delegation.completed。忽略它们不影响协议兼容。

error

{"type": "error", "error": {"type", "code", "message", "param", "client_event_id"}}。部分错误只拒绝这一条事件，会话继续，见实时语音错误码。

完整的事件字段见事件参考。

握手错误

握手失败时返回 OpenAI 格式的 JSON 错误。浏览器的 WebSocket 读不到状态码与响应体，只会触发 onerror，排查时请用服务端程序或 curl。

live_webrtc_not_supported: 400

用了 POST（WebRTC 的建会话方式），请改用 WebSocket。

websocket_required: 426

不是 WebSocket 升级请求，或连接了 cn.nexusvai.xyz。

invalid_api_key: 401

密钥缺失、格式错误或已撤销。

model_not_in_whitelist: 403

密钥的白名单不包含 gpt-live-1。绑定了模型分组时返回 model_not_in_group；账户被限制时返回 account_suspended。

key_token_quota_exhausted: 429

密钥的累计 token 上限已用完；累计请求数用完时为 key_request_quota_exhausted。

live_rate_limited: 429

每分钟新建的会话数超过本档上限，按 Retry-After 等待。

live_concurrency_limit: 429

同时进行的会话数达到本档上限。关闭一个会话后重试。

live_capacity_exhausted: 503

语音服务繁忙；service_unavailable 与 live_disabled 表示暂时不可用。按 Retry-After 重试。

限流错误的响应头带 X-Cancri-Live-Tier、X-Cancri-Live-Max-Concurrent 与 X-Cancri-Live-Max-Duration（秒）。各档位的会话限制见计费与限制。

import WebSocket from "ws";

const url = "wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions";
const ws = new WebSocket(url, {
  headers: { Authorization: `Bearer ${process.env.CANCRI_API_KEY}` },
});

ws.on("open", () => {
  ws.send(JSON.stringify({
    type: "session.start",
    session: {
      model: "gpt-live-1",
      instructions: "你是一个简洁的中文语音助手。",
      audio: { format: { type: "audio/pcm", rate: 24000 }, output: { voice: "marin" } },
    },
  }));
});

ws.on("message", (buf) => {
  const event = JSON.parse(buf.toString());
  if (event.type === "session.started") {
    // 开始持续发送 session.input_audio.append
  }
  if (event.type === "session.output_transcript.delta") process.stdout.write(event.delta);
  if (event.type === "error") console.error(event.error);
});
import asyncio, json, os
import websockets

URL = "wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions"

async def main():
    headers = {"Authorization": f"Bearer {os.environ['CANCRI_API_KEY']}"}
    async with websockets.connect(URL, additional_headers=headers, max_size=None) as ws:
        await ws.send(json.dumps({
            "type": "session.start",
            "session": {"model": "gpt-live-1", "audio": {"format": {"type": "audio/pcm", "rate": 24000}}},
        }))
        async for raw in ws:
            event = json.loads(raw)
            if event["type"] == "session.output_transcript.delta":
                print(event["delta"], end="", flush=True)
            elif event["type"] == "error":
                print("error", event["error"])

asyncio.run(main())
