API 参考
Messages

计算输入 token 数

POST
/v1/messages/count_tokens

估算一个 Messages 请求会消耗多少输入 token。Claude Code 在发送消息前会自动调用它来管理上下文长度，你不需要手动配置。

结果由网关在本地估算，不请求模型，所以与实际计费的 input_tokens 可能有出入，并且会略微偏大。调用不计费，也不计入 RPM 与 TPM。

请求体

与 Messages 请求体相同，只有下面的字段参与估算。

model: string可选

不参与估算，也不校验，可以照常传入。

messages: array of object必填

统计 text、tool_use（名称与输入）、tool_result 中的文本。每张 image 按 250 个 token 计，每个 document 按 2,000 个字符计，每条消息另加 4 个 token。

system: string or array可选

系统提示中的文本。

tools: array of object可选

工具的 name、description 与 input_schema，每个工具另加 8 个 token。

文本按约 3.5 个字符折合 1 个 token 计算。请求体最大 10 MB。

返回
input_tokens: integer

估算的输入 token 数，最小为 1。

错误

错误使用 Anthropic 格式，只有 error.type，不含 code。

invalid_request_error: 400 / 413

请求体不是合法的 JSON，Content-Length 无效，或请求体超过 10 MB（413）。

authentication_error: 401

密钥缺失或无效。

permission_error: 403

账户已被限制使用。

rate_limit_error: 429

每个密钥每分钟最多调用 600 次，超出后带 Retry-After: 60。同一网络多次使用无效密钥时也会返回 429。

api_error: 503

认证服务暂时不可用，可以重试。

curl https://cn.nexusvai.xyz/v1/messages/count_tokens \
  -H "Content-Type: application/json" \
  -H "x-api-key: $CANCRI_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-sonnet-5.5",
    "system": "你是一个简洁的助手。",
    "messages": [{"role": "user", "content": "用一句话解释什么是 RLS。"}]
  }'
import os
from anthropic import Anthropic

client = Anthropic(
    base_url="https://cn.nexusvai.xyz",
    api_key=os.environ["CANCRI_API_KEY"],
)

result = client.messages.count_tokens(
    model="claude-sonnet-5.5",
    system="你是一个简洁的助手。",
    messages=[{"role": "user", "content": "用一句话解释什么是 RLS。"}],
)
print(result.input_tokens)
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://cn.nexusvai.xyz",
  apiKey: process.env.CANCRI_API_KEY,
});

const result = await client.messages.countTokens({
  model: "claude-sonnet-5.5",
  system: "你是一个简洁的助手。",
  messages: [{ role: "user", content: "用一句话解释什么是 RLS。" }],
});
console.log(result.input_tokens);
