    价格

    所有价格以人民币（¥）计。按 token 计费的模型列出每百万 token 的输入、输出与缓存命中价格，按次计费的模型单独列出。

    实时语音

    GPT-Live 全双工实时语音。

    GPT-Live（gpt-live-1）通过 WebSocket 接入，语音部分按秒计费，委派给后端模型的部分另行计费。具体价格与计费规则见实时语音计费。

    计费说明

    • 按 token 计费的模型分别对输入与输出计价，单位为每百万 token（1M tokens）。
    • 命中缓存的输入 token 默认按输入价格的 1 折计费，Claude Opus 5.5（含 Thinking）按 3 折，以价格表中的缓存命中价为准；上游返回缓存写入用量（cache write）时，写入部分按输入价格的 1.25 倍计费。
    • 按次计费的模型，每次成功的请求按固定价格扣费一次，与 token 数量无关。
    • 扣费以响应中的 usage 为准。返回 4xx 或 5xx 的失败请求不扣费；未定价的模型不可调用，返回 402 model_not_priced。
    • 标有「免费」的模型不扣余额，调用计入免费额度，并受速率限制约束，详见免费模型与免费额度。
    • API 调用从账户的 API 余额扣费，团队 API 密钥从团队余额扣费。充值与账单在控制台查看。
