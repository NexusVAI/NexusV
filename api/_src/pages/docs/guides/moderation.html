--- title: 内容审核 description: 设计应用侧的文本与图像内容审核流程，区分生成结果、审核分数和人工复核。 tab: models lead: false ---

NexusVAI 公共 API 未开放独立的 /v1/moderations 端点。不要依赖文本生成请求返回专用的审核分类或分数。可用 API 见端点列表。

内容审核是应用在接收输入、显示输出或执行后续动作之前，按自己的规则检查内容的步骤。审核和生成应分别测试；生成模型的拒答不等于应用已经完成审核。

选择审核流程

  • 为文本、图像等输入分别定义判定规则，说明何时允许、拦截或转人工。
  • 先检查输入，再在展示生成结果或调用工具前检查输出。
  • 遇到系统超时或结果缺失时执行预先定义的降级策略，不把缺少审核信号当作放行。

审核生成内容

将文本生成与应用的审核决策解耦。使用流式输出时，先区分可暂存的增量和允许显示的结果；涉及高风险动作时，等待审核及人工确认后再继续。

对独立输入分类

用应用自有的审核规则或专用服务给输入分类。将类别、证据、处理结果及人工复核状态记录在应用中，不把分类阈值仅写在模型提示词里。

儿童安全：不要将已知或疑似儿童性虐待材料发送给通用生成或审核模型。按适用法规和组织的专门流程处理和报告。

理解审核结果

分类分数不等同于事实或违规概率，也通常不能跨模型直接比较。用样例测量误判、漏判及阈值变化，再确定是否自动处理或转人工。

查看支持的类别

类别由你使用的审核系统定义。按产品受众、输入模态和业务风险制定清单，明确每类对应的处理方式，并确保能够复核和申诉。

使用 OpenAI 审核模型检测文本和图片中的有害内容。你可以用审核接口单独对输入分类，也可以在生成回复的同时请求审核分数。根据结果执行你的应用策略，例如过滤内容、把请求转人工复核，或处理提交了违规内容的账户。

omni-moderation-latest 模型接受文本和图片输入，不对音频分类。审核接口免费使用，图片文件最大 20 MB。

儿童安全：请勿将已知或疑似的儿童性虐待材料（CSAM）发送给审核 API。该 API 并非为 CSAM 检测或处理而设计，也不能替代专门的儿童安全防护。关于预防、检测、响应和举报 CSAM 的步骤，请参阅我们的 CSAM 指南。

选择审核流程

流程 适用场景
审核生成内容 你的应用通过 Responses API 或 Chat Completions API 生成文本，并需要审核信号。
对独立输入分类 你的应用需要对文本或图片分类，但不需要生成模型回复。
理解审核结果 你的应用需要解读标记、类别、分数或适用的输入类型。
查看支持的类别 你的应用需要了解哪些有害类别适用于文本、图片或两者。

审核生成内容

如果你的应用需要同时获得生成文本和审核分数，请在生成请求中传入顶层 moderation 对象。API 会同时返回模型输入和生成输出的审核分数，无需单独发起审核请求。

模型仍按正常方式生成内容。在把输出展示给用户或执行后续操作前，请先检查审核结果。

package main

import (
	"context"
	"errors"
	"fmt"

	"github.com/openai/openai-go/v3"
	"github.com/openai/openai-go/v3/responses"
)

func main() {
	client := openai.NewClient()

	response, err := client.Responses.New(context.Background(), responses.ResponseNewParams{
		Model: "gpt-6-astra",
		Input: responses.ResponseNewParamsInputUnion{
			OfString: openai.String("A user asks for instructions to make a harmful weapon. Draft a brief refusal and offer a safer alternative."),
		},
		Moderation: responses.ResponseNewParamsModeration{
			Model: "omni-moderation-latest",
		},
	})
	if err != nil {
		panic(err)
	}

	switch inputModeration := response.Moderation.Input.AsAny().(type) {
	case responses.ResponseModerationInputModerationResult:
		fmt.Println(inputModeration.Flagged)
	case responses.ResponseModerationInputError:
		panic(errors.New(inputModeration.Message))
	default:
		panic("unexpected input moderation result")
	}
	switch outputModeration := response.Moderation.Output.AsAny().(type) {
	case responses.ResponseModerationOutputModerationResult:
		fmt.Println(outputModeration.Flagged)
	case responses.ResponseModerationOutputError:
		panic(errors.New(outputModeration.Message))
	default:
		panic("unexpected output moderation result")
	}
}

import com.openai.client.okhttp.OpenAIOkHttpClient;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;

ResponseCreateParams params =
    ResponseCreateParams.builder()
        .model("gpt-6-astra")
        .input(
            "A user asks for instructions to make a harmful weapon. Draft a brief refusal and offer a safer alternative.")
        .putAdditionalBodyProperty(
            "moderation", JsonValue.from(Map.of("model", "omni-moderation-latest")))
        .build();

var response = client.responses().create(params);
var moderation =
    response
        .moderation()
        .orElseThrow(
            () -> new IllegalStateException("The response did not include moderation results"));
List flags = new ArrayList<>();

var input = moderation.input();
if (input.isError()) {
  throw new IllegalStateException(input.asError().message());
}
if (!input.isModerationResult()) {
  throw new IllegalStateException("Missing input moderation flag");
}
flags.add(input.asModerationResult().flagged());

var output = moderation.output();
if (output.isError()) {
  throw new IllegalStateException(output.asError().message());
}
if (!output.isModerationResult()) {
  throw new IllegalStateException("Missing output moderation flag");
}
flags.add(output.asModerationResult().flagged());

flags.forEach(System.out::println);

import (
	"context"
	"errors"
	"fmt"

	"github.com/openai/openai-go/v3"
)

func main() {
	client := openai.NewClient()

	completion, err := client.Chat.Completions.New(context.Background(), openai.ChatCompletionNewParams{
		Model: "gpt-6-astra",
		Messages: []openai.ChatCompletionMessageParamUnion{
			openai.UserMessage("A user asks for instructions to make a harmful weapon. Draft a brief refusal and offer a safer alternative."),
		},
		Moderation: openai.ChatCompletionNewParamsModeration{
			Model: "omni-moderation-latest",
		},
	})
	if err != nil {
		panic(err)
	}

	switch inputResult := completion.Moderation.Input.AsAny().(type) {
	case openai.ChatCompletionModerationInputModerationResults:
		if len(inputResult.Results) == 0 {
			panic("missing input moderation result")
		}
		fmt.Println(inputResult.Results[0].Flagged)
	case openai.ChatCompletionModerationInputError:
		panic(errors.New(inputResult.Message))
	default:
		panic("unexpected input moderation result")
	}
	switch outputResult := completion.Moderation.Output.AsAny().(type) {
	case openai.ChatCompletionModerationOutputModerationResults:
		if len(outputResult.Results) == 0 {
			panic("missing output moderation result")
		}
		fmt.Println(outputResult.Results[0].Flagged)
	case openai.ChatCompletionModerationOutputError:
		panic(errors.New(outputResult.Message))
	default:
		panic("unexpected output moderation result")
	}
}

Chat Completions 在 completion.moderation.input 和 completion.moderation.output 返回审核结果容器。如果请求只生成一个选项，请读取 results[0] 获取输入和输出的第一条结果。如果请求了多个选项，completion.moderation.output.results[i] 与 completion.choices[i] 一一对应。

内嵌的审核结果与独立审核结果使用相同的类别字段。先看 flagged 做初步判断，再用 categories 和 category_scores 做日志记录、分流、审计或人工复核队列。即使是拒绝或其他安全相关的回复，只要讨论了有害内容，仍可能被标记。请把审核分数当作应用策略的信号，而不是自动拦截的依据。

如果你的应用需要处理审核失败的情况，请先检查审核结果的类型，再读取分数。如果某个审核步骤无法完成，对应的输入或输出审核字段可能包含错误信息，而不是审核分数。

对于工具调用请求，只要工具调用参数和工具输出出现在对话内容中，审核就会覆盖它们。审核不覆盖工具名称、工具描述、工具 schema 或响应格式 schema。

如果你以流式方式接收生成的回复，审核分数会在完整输出生成后才返回，不会随部分输出增量一起发送。

JSON 响应包含的字段描述了输入中出现了哪些类别，以及模型对每个类别的置信度。

输出字段说明
flagged

模型判定内容可能有害时设为 true，否则为 false。

categories

包含每个类别的违规标记字典。对每个类别，模型判定该类别违规时值为 true，否则为 false。

category_scores

包含每个类别的分数字典。每个分数表示模型对输入包含该类别内容的置信度，取值在 0 到 1 之间，越高表示置信度越高。

category_applied_input_types

包含该类别分数适用的输入类型。例如，若 violence/graphic 类别同时适用于图片和文本输入，则 violence/graphic 属性为 ["image", "text"]。

我们计划持续升级审核接口的底层模型。因此，依赖 category_scores 的自定义策略可能需要随时间重新校准。

标注为“仅文本”的类别不支持图片输入。如果你只向 omni-moderation-latest 模型发送图片（不附带文本），模型会对这些不支持的类别返回 0 分。图片文件最大 20 MB。

hate/threatening

基于种族、性别、族裔、宗教、国籍、性取向、残障状况或种姓的仇恨内容，其中还包含针对目标群体的暴力或严重伤害。
