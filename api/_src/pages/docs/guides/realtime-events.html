--- title: 事件参考 description: 实时语音会话中客户端与服务端交换的全部事件，包括 NexusVAI 扩展的 cancri.* 事件。 tab: realtime ---

会话中的所有事件都是 JSON 文本帧，二进制帧会被拒绝。服务端按白名单处理客户端事件：不在下表中的事件类型会收到 error 事件，不会转发给上游，也不收费。

客户端事件

type字段说明
session.startsession第一条事件，只能发送一次。见配置 session.start。
session.input_audio.appendaudio（base64）持续发送麦克风音频。单条 base64 最多 2,000,000 个字符，建议每块 20–100 ms。
session.input_audio.mute
session.input_audio.unmute		—暂停或恢复收音。
session.output_audio.fixture.playaudio（base64）OpenAI 协议原有事件，含义与 OpenAI 文档相同。单条长度限制同上。
session.commentary.append
session.thinking.append
session.instructions.append		content、delegation_id向语音层追加内容，content 最多 8,000 个字符。见只买语音层。
session.updatesession.delegation.responses仅官方后端模式。修改后端参数。
response.item.createitem仅官方后端模式。交回函数执行结果。
response.create—仅官方后端模式。让后端继续生成。
session.close—结束会话。服务端返回 session.closed 后断开连接。

会话开始后，服务端按上表的字段重建每条事件再转发，多余的字段会被丢弃。只有 session.start 会因为未知字段而被拒绝。

用 event_id 关联错误

客户端事件都可以带 event_id（最多 128 个字符）。session.start 之后的事件被拒绝时，error 事件会在 error.client_event_id 中带回这个值，方便你对应到具体的请求。

服务端事件

以下事件来自 OpenAI Live 协议，由服务端原样转发。上游的其他事件也会转发，客户端应忽略不认识的类型。

type说明
session.started会话已开始。session.id 是上游会话 id。
session.output_audio.deltadelta：回复音频（base64），格式与 audio.format 相同。
session.input_transcript.deltadelta：用户语音的转写增量。
session.output_transcript.deltadelta：回复的转写增量。
session.delegation.created语音层发起了一次委派。只买语音层模式下需要你来回答。
session.commentary.appended 等追加事件的确认。client_event_id 对应你发送的 event_id。
response.event官方后端模式下嵌套的 Responses 流式事件（在 event 字段里），包括工具调用和带 usage 的 response.completed。
session.usage.updatedusage.seconds：截至目前的累计计费秒数。它是总数，不要相加。
session.closed会话已结束。usage.seconds 是最终计费秒数。
error错误，格式见下文。

error 事件

格式与 OpenAI 相同。由 NexusVAI 生成的错误 event_id 以 evt_cancri_ 开头：

{
  "type": "error",
  "event_id": "evt_cancri_...",
  "error": {
    "type": "invalid_request_error",
    "code": "immutable_field_update",
    "message": "session.audio cannot be changed after start.",
    "param": "session.audio",
    "client_event_id": "update_1"
  },
  "client_event_id": "update_1"
}

全部错误码及是否会断开会话，见会话中的错误。

NexusVAI 扩展事件

以 cancri. 开头的事件由 NexusVAI 发出，用于显示费用和会话状态。忽略这些事件不影响协议兼容。

type何时发送
cancri.session.created会话开始时一次，紧跟在 session.started 之后。
cancri.billing.updated会话进行中约每 10 秒一次；结束时再发一次 final: true。
cancri.session.closing服务端即将结束会话时。
cancri.delegation.completed站内模型模式下，每次后端回答完成或失败时。

cancri.session.created

{
  "type": "cancri.session.created",
  "session_id": "live_9c93...",
  "upstream_session_id": "live_u7_...",
  "mode": "official",
  "backend_model": "gpt-6-luna",
  "limits": { "max_duration_seconds": 1800, "idle_timeout_seconds": 90, "segment_seconds": 30 },
  "pricing": {
    "currency": "CNY",
    "voice_per_second": 0.009,
    "backend_input_per_million": 1.2,
    "backend_cached_input_per_million": 0.12,
    "backend_output_per_million": 6,
    "web_search_per_call": 0.12
  }
}
字段说明
session_idNexusVAI 会话 id，以 live_ 开头。
upstream_session_id上游会话 id，与 session.started 中的 session.id 相同。
modeofficial、site 或 voice_only。
backend_model官方后端为 gpt-6-luna，站内模型模式为你选的模型，只买语音层为 null。
limits.max_duration_seconds本档单个会话的最长秒数。
limits.idle_timeout_seconds空闲多少秒后服务端结束会话。
limits.segment_seconds每段预扣的秒数。
pricing本会话的单价（人民币元）。backend_* 与 web_search_per_call 只在官方后端模式下有值，其他模式为 null。

cancri.billing.updated

{
  "type": "cancri.billing.updated",
  "final": false,
  "seconds": 21,
  "prepaid_through_seconds": 30,
  "voice_cny": 0.189,
  "backend_tokens": { "input": 5161, "output": 272 },
  "backend_cny": 0.007825,
  "web_search_calls": 1,
  "web_search_cny": 0.12,
  "total_cny": 0.316825,
  "estimated": true
}
字段说明
final会话结束时的最后一次为 true。
estimated与 final 相反。会话进行中的金额是估算值。
seconds截至目前的计费秒数。
prepaid_through_seconds已经预付到第几秒。
voice_cny语音费。
backend_tokens、backend_cny官方后端累计的输入 / 输出 token 及费用。
web_search_calls、web_search_cny联网次数及费用。
total_cny以上合计。

这些金额用于显示，实际扣费以账户账单为准。backend_* 只统计官方后端；站内模型的费用按普通 API 调用单独记账，请看 cancri.delegation.completed 或控制台的用量页。

cancri.session.closing

{
  "type": "cancri.session.closing",
  "reason": "insufficient_balance",
  "closes_in_seconds": 12,
  "message": "余额不足，会话将在已预付时长用完后结束。"
}
  • reason：结束原因，取值见会话何时结束。会话没能开始时，reason 与 error 事件的 code 相同。
  • closes_in_seconds、message：只在余额不足时出现，提前告诉你还剩多少秒。
  • upstream_close：只在上游连接中断、且没有拿到最终用量时出现，包含上游的关闭码和原因。

你主动发送 session.close 或自己断开连接时，不会收到这个事件。

cancri.delegation.completed

站内模型模式下，每次后端回答结束时发送。成功时：

{
  "type": "cancri.delegation.completed",
  "delegation_id": "item_...",
  "model": "claude-haiku-5.5",
  "ok": true,
  "latency_ms": 6995,
  "usage": { "prompt_tokens": 8727, "completion_tokens": 66 },
  "text": "..."
}

失败时 ok 为 false，并带上 error。error.code 是后端调用返回的错误码（拿不到时为 http_<状态码>），超时为 backend_timeout：

{
  "type": "cancri.delegation.completed",
  "delegation_id": "item_...",
  "model": "claude-haiku-5.5",
  "ok": false,
  "error": { "code": "backend_timeout", "message": "..." }
}
