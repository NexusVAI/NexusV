--- title: 客户端常见问题 description: 排查编程工具和聊天客户端接入时常见的 Base URL、模型 ID、密钥、缓存与维护问题。 tab: coding ---

大多数接入问题出在三项配置上：Base URL、API 密钥和模型 ID。先按下面的错误信息对号入座；拿不准请求有没有到达 NexusVAI 时，用 GET /v1/balance 查看这个 Key 最近的调用记录。

Base URL 填写错误

OpenAI 兼容的工具填 https://cn.nexusvai.xyz/v1，Anthropic 兼容的工具（Claude Code、Anthropic SDK、OpenClaw 的 anthropic-messages）填 https://cn.nexusvai.xyz。填错时会看到：

错误原因解决方法
421 relay_path_not_supported请求路径不在 /v1/ 下，通常是 OpenAI 兼容工具的 Base URL 少了末尾的 /v1。改成 https://cn.nexusvai.xyz/v1。
404，消息为 Not found: /v1/v1/…Base URL 多了一个 /v1，常见于 Anthropic 兼容工具。Anthropic 兼容工具改成 https://cn.nexusvai.xyz。
426 websocket_required用 cn.nexusvai.xyz 连接实时语音。实时语音改用 chat.nexusvai.xyz，见连接与认证。

模型不存在

OpenAI 兼容端点返回 404 model_not_found；Anthropic 兼容的 /v1/messages 返回 404，type 为 not_found_error。两者的消息都是 The model '…' does not exist.。

  • 模型 ID 必须与 GET /v1/models 的返回值完全一致，包括大小写和连字符。
  • 部分客户端会自动改写模型名。遇到这种情况，在模型设置中手动填入 NexusVAI 的模型 ID，例如 gpt-6-astra、claude-opus-5.5。
  • 模型厂商带日期的原始版本号（例如 claude-3-5-sonnet-20241022）和其他服务的别名不可用。

API 密钥无效

返回 401 invalid_api_key 时，按以下几点检查：

  • Key 必须以 cancri_sk_ 开头，在控制台创建。
  • 网页登录的会话、Cookie 或登录令牌不能代替 API 密钥。
  • 命令行工具从环境变量读取 Key 时，变量必须在启动工具的同一个终端里生效。
  • 已撤销的 Key 无法恢复，请创建新 Key。

提示缓存

NexusVAI 支持提示缓存。缓存命中（cache read）的输入 token 按该模型的缓存价格计费，通常为输入价格的 1 折，按每个请求的实际命中量结算。各模型的价格见价格。

第三方检测工具显示「无缓存」，通常有两个原因：

  • 字段格式不同。部分工具按 NewAPI、Sub2API 等服务的响应格式或日志字段判断缓存。NexusVAI 的字段位置和命名不同，工具读不到时会显示「无缓存」，但缓存仍然生效。
  • 没有满足命中条件。缓存命中要求请求前缀完全一致、长度达到模型的最低要求，而且缓存只保留几分钟（Anthropic 默认约 5 分钟）。单次请求或前缀不断变化的检测请求不会命中。

出于安全考虑，响应的 usage 不返回每个请求的缓存命中 token 数。缓存折扣已经计入每次调用的扣费，可以用 GET /v1/balance 返回的 cost 或控制台的用量页核对。Anthropic 协议请求中的 cache_control 不生效，前缀缓存按实际命中自动计费。

API 暂停服务

API 暂停服务期间（例如维护），GET /v1/models 仍可读取模型列表，其他接口返回 503 api_paused 并带 Retry-After 头。更换 Key 或客户端都无法解除，请等待恢复。

免费账户与已充值账户

未充值、也没有套餐的账户处于 Tier 0：60 RPM、2,000,000 TPM，免费模型还受免费额度限制（每个账户每 24 小时滚动窗口 1 亿 token）。累计充值达到 ¥10 或开通套餐后，档位提升，免费模型不再受免费额度限制。详见速率限制。

图像与视频生成

API 不提供图像与视频生成。/v1/images/generations 与 /v1/videos/generations 只对网页版开放，使用 cancri_sk_ 开头的 Key 调用会返回 403 endpoint_disabled。

API 密钥泄露

立即在控制台的 API 密钥页撤销这个 Key，然后创建新 Key，并更新所有客户端的配置。撤销立即生效，已撤销的 Key 无法恢复。
