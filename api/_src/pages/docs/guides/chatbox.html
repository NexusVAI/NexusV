Chatbox 是一款桌面 AI 客户端，支持 OpenAI 兼容端点。把模型提供方设为 OpenAI 兼容并填入 NexusVAI 的地址，就能使用 NexusVAI 的模型。

前提条件

  • 已安装 Chatbox。
  • 一个 NexusVAI API 密钥，可以在控制台创建。

配置模型提供方

  1. 启动 Chatbox，点击左下角的 设置。
  2. 模型提供方 选择 OpenAI 兼容，按下表填写。
  3. 在 模型 输入框中填入模型 ID，或点击刷新加载列表。
  4. 保存设置。
设置项值
API 密钥cancri_sk_...
API 域名 / Base URLhttps://cn.nexusvai.xyz/v1
模型NexusVAI 模型 ID，例如 gpt-6-astra

验证配置

保存后发送一条简短的消息。收到回复就说明模型 ID、Key 和 Base URL 都有效。要核对这次调用的扣费，可以查询 GET /v1/balance，见验证请求是否到达 NexusVAI。

排查问题

现象可能的原因解决方法
404 model_not_found模型 ID 与 GET /v1/models 不一致。改成列表中的 id，或点击刷新后从列表中选择。
421 relay_path_not_supportedBase URL 少了末尾的 /v1。填 https://cn.nexusvai.xyz/v1。
401 invalid_api_keyKey 填错或已撤销。在控制台确认 Key 状态。
