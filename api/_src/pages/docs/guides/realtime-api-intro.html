用 Realtime API 构建语音到语音的智能体。模型直接处理音频，维护对话状态，并可以调用工具。本指南从浏览器应用的 Agents SDK 开始；如需直接控制连接，请使用更底层的连接指南。

如需与独立的委托后端配合做全双工对话，请参阅 GPT-Live。如需比较语音架构和串联式流水线，请参阅语音智能体。

构建语音到语音的智能体

当交互需要像对话一样即时时，使用 Realtime API。对于需要打断、低首包音频延迟、自然轮替和实时工具调用的语音智能体，这是最合适的起点。

常见的浏览器流程如下：

  1. 你的应用服务端为 Realtime 会话创建一个临时客户端密钥。
  2. 前端创建一个 RealtimeSession。
  3. 会话在浏览器中通过 WebRTC 连接，在服务端则通过 WebSocket 连接。
  4. 智能体在该会话内处理音频轮次、工具、打断和交接。
import { RealtimeAgent, RealtimeSession } from "@openai/agents/realtime";

const agent = new RealtimeAgent({
  name: "Assistant",
  instructions: "You are a helpful voice assistant.",
});

const session = new RealtimeSession(agent, {
  model: "gpt-realtime-2.1",
});

await session.connect({
  apiKey: "ek_...(ephemeral key from your server)",
});

之后，为 RealtimeAgent 添加工具、交接和护栏的方式与文本智能体相同。音频传输相关的逻辑放在会话层，业务逻辑放在智能体定义中。

如果需要更底层的控制，请先阅读传输相关文档：

  • 音频与语音概览

  • 使用 WebSocket 的 Realtime API

安全标识符

如果你的应用能识别具体的终端用户，请在 Realtime API 请求中附带安全标识符。OpenAI 推荐使用安全标识符，但不强制要求。它帮助 OpenAI 发现有害行为，并把处置范围限定到具体用户，而不是整个组织。请使用稳定且保护隐私的值，例如内部用户 ID 的哈希。

在 Realtime API 请求中，把标识符放在 OpenAI-Safety-Identifier 请求头里。使用临时令牌时，在服务端创建客户端密钥的请求上设置该请求头，把标识符与会话关联起来。从可信服务端通过 WebSocket 或统一的 WebRTC 接口连接时，在连接请求上设置该请求头。

安全标识符不会从 Responses API 请求或其他会话中继承。如果你在应用的其他地方使用了 Responses API 的 safety_identifier 参数，那么在创建或连接每个 Realtime 会话时，请传入相同的稳定值。

从 Beta 迁移到正式版（GA）

如果你的 Realtime 集成仍在使用 Beta 接口，请先迁移到 GA 接口，再开展新的工作。主要变化如下：

  • 调用 GA 接口时，去掉 OpenAI-Beta: realtime=v1 请求头。
  • 为浏览器或移动端客户端创建临时凭证时，使用 POST /v1/realtime/client_secrets。
  • 建立 WebRTC 会话时，使用 /v1/realtime/calls。
  • 更新会话和事件的结构以适配 GA 接口。具体来说，要设置 session.type，把输出音频配置移到 session.audio.output 下，并使用较新的响应事件名，例如 response.output_text.delta、response.output_audio.delta 和 response.output_audio_transcript.delta。
  • 如果要推进语音到语音的应用，请从浏览器示例开始。如果要推进转写工作流，请使用 Realtime 转写。

当前的 GA 流程请参阅 Realtime 客户端事件参考、Realtime 会话参考和浏览器示例。

后续步骤

  • 管理对话：配置会话，处理音频、文本和事件。
  • 语音活动检测：配置自动轮次检测。
  • 工具与 MCP：添加函数、MCP 服务器和连接器。
  • 语音模型提示词：使用与你的 Realtime 模型对应的指南。
  • 成本优化：了解 Realtime 的计费和缓存。
  • 服务端控制：把工具执行和会话控制保留在你的服务端。

其他音频工作流

工作流选择和通用音频术语现在位于音频与语音页面。连续翻译请使用实时翻译；实时字幕请使用实时转写；录制好的音频请使用文件转写。
