--- title: CC Switch description: 在 CC Switch 中添加 NexusVAI provider，为 Claude Code、Codex 等编程工具统一切换 Base URL 和 API 密钥。 tab: coding ---

CC Switch 是一款统一管理 AI 编程命令行工具（Claude Code、Codex、OpenCode、OpenClaw 等）的桌面客户端，可以为不同工具注入不同的 Base URL 和 API 密钥。

前提条件

  • 已安装 CC Switch，以及要切换的编程工具。
  • 一个 NexusVAI API 密钥，可以在控制台创建。

添加 provider

  1. 打开 CC Switch，进入 Settings → Providers。
  2. 点击 Add Custom Provider。
  3. 按目标工具填写 Base URL 和 API Key（见下表）。
  4. 点击 Test Connection。
  5. 启用这个 provider。
目标工具Base URL
Claude Code 等 Anthropic 协议工具https://cn.nexusvai.xyz（末尾不要带 /v1）
Codex、OpenCode 等 OpenAI 兼容工具https://cn.nexusvai.xyz/v1

API Key 都填 cancri_sk_...。

验证配置

Test Connection 通常只请求 /v1/models。能拉取模型列表，不代表推理请求可用。启用 provider 后，分别用 Claude Code 或 Codex 发送一个最短的请求，再查询这个 Key 最近的调用，确认请求发到了 NexusVAI：

curl "https://cn.nexusvai.xyz/v1/balance?limit=5" \
  -H "Authorization: Bearer cancri_sk_..."

字段说明见验证请求是否到达 NexusVAI。

排查问题

现象可能的原因解决方法
Test Connection 成功，但 Claude Code 请求 404给 Anthropic 协议工具填了带 /v1 的地址，请求变成 /v1/v1/messages。改成 https://cn.nexusvai.xyz。
Codex 请求返回 421 relay_path_not_supported给 OpenAI 兼容工具填的地址少了 /v1。改成 https://cn.nexusvai.xyz/v1。
切换后请求仍发往原来的服务provider 没有启用，或工具没有重新启动。启用 provider 后重启对应的工具。
