--- title: Claude Code description: 设置两个环境变量，让 Claude Code 通过 Anthropic Messages 协议使用 NexusVAI 的模型。 tab: coding ---

Claude Code 是 Anthropic 的终端编程智能体，使用 Anthropic Messages 协议。把 Base URL 和 API 密钥换成 NexusVAI 的，就能在 Claude Code 中调用 NexusVAI 的模型，包括非 Claude 系列的模型。

前提条件

  • 已安装 Claude Code。
  • 一个 NexusVAI API 密钥，可以在控制台创建。

设置环境变量

export ANTHROPIC_BASE_URL="https://cn.nexusvai.xyz"
export ANTHROPIC_API_KEY="cancri_sk_..."
claude
$env:ANTHROPIC_BASE_URL = "https://cn.nexusvai.xyz"
$env:ANTHROPIC_API_KEY = "cancri_sk_..."
claude

Base URL 不要带 /v1。Claude Code 会在 ANTHROPIC_BASE_URL 后面自动拼接 /v1/messages 和 /v1/messages/count_tokens。填成 https://cn.nexusvai.xyz/v1 会请求 /v1/v1/messages，返回 404。

选择认证方式

两个变量对应两种请求头，NexusVAI 都接受：

环境变量发送的请求头何时使用
ANTHROPIC_API_KEYx-api-key: cancri_sk_...默认方式。
ANTHROPIC_AUTH_TOKENAuthorization: Bearer cancri_sk_...你的环境要求使用 Bearer 认证时。

只设置其中一个。如果两个都设置了，请确保它们是同一个 Key。

启动后会发生什么

  • Claude Code 请求 GET /v1/models。请求带 anthropic-version 头，NexusVAI 会返回 Anthropic 格式的模型列表。
  • 它调用 /v1/messages/count_tokens 估算上下文长度。这个端点不计费，不需要额外配置。
  • 对话通过 /v1/messages 以流式输出返回。

选择模型

模型 ID 必须在 GET /v1/models 的列表里，例如 claude-opus-5.5、claude-sonnet-5.5、claude-haiku-5.5。模型厂商带日期的原始版本号（例如 claude-3-5-sonnet-20241022）不可用。

模型选择器里显示哪些模型，由 Claude Code 自己的过滤规则决定。/v1/messages 不限于 Claude 系列：gpt-6-astra、deepseek-v4-flash 等模型也能调用，前提是 Claude Code 允许你手动填写模型 ID。

验证配置

在 Claude Code 中发送一条简短的消息，然后用同一个 Key 查询最近的调用：

curl "https://cn.nexusvai.xyz/v1/balance?limit=5" \
  -H "x-api-key: $ANTHROPIC_API_KEY"

recent_usage.data 里应该出现刚才的请求，model 为你选择的模型。字段说明见验证请求是否到达 NexusVAI。

排查问题

现象可能的原因解决方法
404，消息为 Not found: /v1/v1/messagesANTHROPIC_BASE_URL 末尾多了 /v1。改成 https://cn.nexusvai.xyz。
401 invalid_api_keyKey 无效、已撤销，或没有在启动 Claude Code 的终端里设置。检查环境变量，必要时在控制台重新创建 Key。
404 not_found_error：The model '…' does not exist.模型 ID 不在 GET /v1/models 的列表里。换成列表中的 id。
模型选择器里找不到想要的模型Claude Code 按自身规则过滤了列表。手动填写模型 ID。
请求里的 cache_control 没有效果NexusVAI 不处理 cache_control，前缀缓存按实际命中自动计费。见提示缓存。

下一步

了解 /v1/messages 支持的字段和不支持的功能。 在 Claude Code、Codex 等工具之间切换 provider。 缓存、维护和模型 ID 相关的排查。
