--- title: 图像提示词 description: 为网页中的图像生成和编辑任务编写提示词，控制构图、细节和局部修改。 tab: models lead: false ---

用图像提示词描述期望的画面和约束。你可以在 NexusV 对话中使用可用的图像功能；NexusVAI 公共 API 未开放图像生成与编辑。通过 API 理解已有图片，请阅读图像与视觉。

概览

先描述主体、场景、构图、风格和用途，再列出必须保留的内容。编辑时说明哪一处要改、其余哪里不能变；每次只调整一个因素，方便判断改动原因。

选择模型

以网页当时可选择的模型为准。需要高保真编辑时，用相同参考图和提示词对照细节保留情况；对延迟敏感时，同时记录生成时间与可接受结果的比例。

模型参数

把硬性需求（例如版式和文字）写清楚。分辨率、质量和透明背景等选项以你选择的工具和模型为准，不要把模型在其他平台的参数照搬到 NexusVAI API。

迁移现有工作流

用同一组提示词、参考图和预算对照候选流程。分别检查文字拼写、产品比例、局部改动和人物特征；不要只看一张图就推断模型更新后的整体效果。

提示词基础

  • 明确画面用途：海报、商品图和界面预览需要不同的构图与留白。
  • 指定可见细节：描述材质、光线、色调、景别和主体位置，而不只写「好看」。
  • 精确文字用引号：指定拼写、位置和字号；交付前检查清晰度与错字。
  • 为参考图分工：按编号写清主体、构图、风格或背景，避免模型混淆。

生成图片

控制风格与光线

一张室内建筑摄影：暖米色墙面和藤椅围绕浅水泳池，自然光透过高窗。广角构图，保留留白与墙面材质。不要出现人物、标志或文字。

渲染精确文字

用「标题仅为『周末工作坊』，横排居中，下方留白」明确位置和完整文本，并在生成后核对。

生成界面预览

列出屏幕尺寸、层级、主要状态和可读性要求。图像是设计参考，不是可交互的前端实现。

编辑图像

以「只改变……，保留……」为句式。先说明要修改的区域，再列出需要保护的构图、光线、文字、背景、主体比例或其他细节。

迁移视觉风格

用编号标明原图与风格参考，要求保留原图主体和视角，只采用参考图的材质、色彩或光线。

做透明背景产品图

如果网页工具支持透明背景，明确写出要保留的边缘和半透明材质，并在导出后检查透明通道。

跨多轮精修图像

把上一版作为参照，每轮修改一处并复述不能改变的内容。需要像素级保持一致时，用专门的编辑工具合成已验证的区域。

更多工作流

给信息图写清阅读顺序、标题、数据与图例；给产品合成图写清尺寸关系、朝向、阴影和需要保留的铭牌。用同一组判断标准比较输出。

试一个完整示例

在支持图像功能的网页中，用一条提示描述场景，再要求只改变一个元素。可从图像生成示例开始。

检查结果

对照原始要求逐项检查：构图、文字、可识别元素、没有要求改动的区域。若结果偏离，先缩小修改范围，不要一口气叠加更多指令。

GPT Image 2.5 提示指南

选择模型、编写有效的提示词，并在编辑中保留细节。

概览

先准备好所需图片，再描述主体、构图、风格和约束。编辑时先指出要改什么、哪些必须保持不变。每次只调整一个地方，然后检查结果。

GPT Image 2.5 提供两种模型。GPT Image 2.5 Flare 是小模型，速度更快，图像质量与 GPT Image 2 相当。GPT Image 2.5 Sunburst 是基础模型，以质量为优化目标，图像质量高于 GPT Image 2。两个模型在精确编辑和主体保持方面都有提升。

API 配置和请求示例见图片生成指南。

选择模型

新工作流先看速度时选 GPT Image 2.5 Flare，先看质量要求高时选 GPT Image 2.5 Sunburst。输出达到要求后，再尝试降低延迟。

从当前图像模型迁移时，以现有的图片质量作为起点。两个模型都支持图片生成、编辑和透明背景。

你当前的工作流 先测试
已有的、经过验证的 GPT Image 2 工作流，并且已满足质量要求 GPT Image 2.5 Flare。检查能否在降低延迟的同时保持可接受的质量。
GPT Image 2 在复杂场景下未达到质量要求 GPT Image 2.5 Sunburst。先确认它能达到所需质量。

若 GPT Image 2.5 Sunburst 达到质量要求，再用相同的提示词和输入测试 GPT Image 2.5 Flare。如果它同样达标且延迟更低，就切换到 Flare。若工作流依赖 Sunburst 的质量优势，就继续使用 Sunburst。

请在自己的工作负载上测量响应时间和质量。结果取决于提示词、参考图、输出尺寸和质量设置；一个工作负载上的提速，不能证明另一个负载也会提速同样的幅度。

模型参数

请求参数与提示词分开设置。

参数 GPT Image 2.5 设置
model gpt-image-2.5-flare（小模型）或 gpt-image-2.5-sunburst（基础模型）
quality auto（默认）、low、medium、high、xhigh 或 max
size auto 或自定义分辨率。常见尺寸：1024x1024（方形）、1536x1024（横版）、1024x1536（竖版）、2048x2048（2K 方形）、2048x1152（2K 横版）、3840x2160（4K 横版）和 2160x3840（4K 竖版）。
background auto、opaque 或 transparent

自定义分辨率使用 WIDTHxHEIGHT，并遵守以下约束：

  • 每一边不超过 3,840 像素。
  • 两边都必须是 16 像素的倍数。
  • 较长边与较短边的比例不能超过 3:1。
  • 总像素数必须在 655,360 和 8,294,400 之间。

输出总像素超过 3,686,400（2560x1440）的，属于实验性输出。

调整 quality 之前，先按上面的工作流选好模型。第一次对比时，若两个模型都支持你显式选择的 quality 设置，就保持不变，提示词、参考图和输出尺寸也保持不变。同一个 quality 标签在不同模型上不意味着相同的图像质量或响应时间。

如果输出不达标，尝试更高的 quality 设置。达标后，再测试更低的设置是否在降低延迟的同时保持可接受的质量。仅当它们能在延迟预算内改善未满足的质量要求时，才使用 xhigh 或 max。更高的设置并不能保证每个提示词都得到更好的结果。

对于透明素材，明确请求 background="transparent"，并使用 PNG 或 WebP。检查解码后图片的 alpha 通道，包括发丝、玻璃、阴影和物体边缘。output_compression 只用于 JPEG 或 WebP 输出，不用于 PNG。

迁移现有工作流

  1. 保存基线。收集有代表性的生产提示词和参考图，包括困难的编辑、精确文字、人脸、产品几何结构和透明素材。记录当前模型、请求设置和结果。
  2. 选择第一个候选模型。如果 GPT Image 2 已满足质量要求，先试用 GPT Image 2.5 Flare，并测试延迟是否改善。如果 GPT Image 2 在复杂场景下不达标，先试用 GPT Image 2.5 Sunburst，并先确认它满足质量要求。第一次对比时，保持提示词、参考图、尺寸和输出格式不变。
  3. 检查完整结果。比较指令遵循、身份和产品保持、文字准确性、非预期改动和透明度。重复请求以衡量一致性。对于编辑工作流，既要测试完整的编辑序列，也要测试单步编辑。
  4. 质量达标后再测延迟收益。如果你从 GPT Image 2.5 Sunburst 开始，且它满足质量要求，就用相同的要求评估 GPT Image 2.5 Flare。只有在质量仍可接受且延迟改善时才切换，否则继续使用 Sunburst。
  5. 每次只调整一个设置。在重写提示词之前，先比较各质量档位。测量典型和慢响应、失败、重试以及每张被接受图片的成本。以当前定价为准，不要假设更快的模型更便宜。
  6. 按工作流逐步上线。候选模型通过验收标准后，先切一小部分流量，监控相同指标，再逐步扩大。在旧模型仍受支持期间，保留它以便回滚。

从 GPT Image 1 或 1.5 迁移时，请参考各选项卡中的标签页，确认参数差异和下线日期。测试候选模型支持的请求设置，不要原样复制旧设置。从 GPT Image 2 迁移时，在对比中保留现有的分辨率和透明度要求。

重复编辑仍可能改动你想保留的细节。请重新说明这些约束，并检查每次结果。如果某个区域必须保持像素级一致，请把获批的编辑合成到原图中，而不完全依赖提示词。

提示词基础

  1. 定义结果。写明主体和用途，例如产品照片、广告或示意图。指定构图、宽高比和重要的位置约束。复杂请求可以用带标签的小节，按场景、主体、细节和约束来组织提示词。
  2. 选择便于维护的格式。简短提示词、描述性段落、类 JSON 结构、指令和标签都能表达同一意图。选择最便于阅读和更新需求的格式，不要依赖特殊语法。
  3. 描述可见细节。说明材质、光线、颜色和视觉媒介。目标是写实时，明确要求“照片级写实”或“真实照片”，并描述取景和质感。相机参数只作为外观提示，不保证物理上精确的模拟。对于广角、电影感、低光、雨天或霓虹场景，要写明尺度、氛围和颜色，而不只依赖情绪词。
  4. 描述人物与动作。说明身体取景、相对比例、视线以及与物体的互动。诸如“全身可见，包括双脚”“低头看打开的书”或“双手自然地握着车把”之类的指令，能让预期的姿势和动作更清晰。
  5. 指定精确文字。把必需的文字放进引号，并描述其位置和排版。必要时逐字母拼写不常见的单词或品牌名。要求不要出现额外文字，然后检查输出中的拼写和可读性。对于小字、信息密集或多种字体，比较 medium 或 high 质量。
  6. 把改动和约束分开。编辑时，写“只改 X”，并列出需要保持的细节，例如身份、几何结构、布局、光线或标签。明确排除项，例如不需要的文字、标志或水印。对于精确的局部编辑，还要说明必须保持不变的饱和度、对比度、箭头、相机角度和周围物体。
  7. 为参考图分配角色。按编号和用途标明每个输入：主体、风格、服装或背景。说明这些输入如何组合，以及哪些元素应该移动到哪里。
  8. 有意识地迭代。把上一次的输出作为下一次编辑的输入，每次只请求一项改动，并重复需要保留的细节。“与之前相同的风格”之类的参考可以承载上下文，但如果结果偏离，要重新说明关键约束。在添加更多指令之前，先比较结果。

import base64
from pathlib import Path

from openai import OpenAI

client = OpenAI()


prompt = """
Create an original, non-infringing logo for a company called Field & Flour, a local bakery.
The logo should feel warm, simple, and timeless. Use clean, vector-like shapes, a strong silhouette, and balanced negative space.
Favor simplicity over detail so it reads clearly at small and large sizes. Flat design, minimal strokes, no gradients unless essential.
Fully transparent background. Deliver a single centered logo with generous padding, clean alpha edges, and no solid backdrop, scenery, checkerboard, or watermark.
"""

result = client.images.generate(
    model="gpt-image-2.5-sunburst",
    prompt=prompt,
    size="1024x1536",
    quality="medium",
    background="transparent",
    output_format="png",
    n=4,  # Generate 4 versions of the logo
)

# Preserve the returned PNG bytes, including the alpha channel.
for index, item in enumerate(result.data, start=1):
    Path(f"logo-generation-{index}-gpt-image-2.5-sunburst.png").write_bytes(
        base64.b64decode(item.b64_json)
    )

# Extract a product from a reference image.
prompt = """
Extract the product from the input image and isolate it on a fully transparent background.
Output: centered product, crisp silhouette, no halos/fringing.
Preserve product geometry and label legibility exactly.
Add only light polishing. Do not add a solid backdrop, checkerboard, scenery, or shadow.
Do not restyle the product; remove the background and preserve clean alpha transparency.
"""

result = client.images.edit(
    model="gpt-image-2.5-sunburst",
    image=[
        ("shampoo.webp", Path("input_images/shampoo.webp"), "image/webp"),
    ],
    prompt=prompt,
    size="1024x1536",
    quality="medium",
    background="transparent",
    output_format="png",
)

Path("extract-product-gpt-image-2.5-sunburst.png").write_bytes(
    base64.b64decode(result.data[0].b64_json)
)
