--- title: 查询余额与用量 description: 用 GET /v1/balance 查询账户余额、当前密钥的限额，以及当前密钥最近的调用记录与扣费。 ---

GET /v1/balance 返回账户余额、当前密钥的用量上限，以及当前密钥最近的调用记录。它不计费，不计入推理接口的 RPM 与 TPM，认证方式与推理接口相同。

查询余额

import os
import requests

resp = requests.get(
    "https://cn.nexusvai.xyz/v1/balance",
    headers={"Authorization": f"Bearer {os.environ['CANCRI_API_KEY']}"},
    params={"limit": 20},
    timeout=10,
)
resp.raise_for_status()
data = resp.json()
print(data["balance"], data["currency"])
for row in data["recent_usage"]["data"]:
    print(row["created_at"], row["model"], row["cost"])
const resp = await fetch("https://cn.nexusvai.xyz/v1/balance?limit=20", {
  headers: { Authorization: `Bearer ${process.env.CANCRI_API_KEY}` },
});
if (!resp.ok) throw new Error(`HTTP ${resp.status}`);
const data = await resp.json();
console.log(data.balance, data.currency);
for (const row of data.recent_usage.data) {
  console.log(row.created_at, row.model, row.cost);
}

查询参数

参数说明
limit可选。返回最近调用记录的条数，取值为 0–100 的整数，默认 20。传 0 时只返回余额，recent_usage.data 为空数组。超出范围或不是整数时返回 400 invalid_limit。

响应字段

字段说明
balance可用余额，单位为元。个人密钥返回账户的 API 余额（该账户下所有个人密钥共用）；团队密钥返回所属团队的团队余额。
debt欠费金额，单位为元，通常为 0。结算时实际费用超过预扣且余额不足时产生，见预扣与结算。
key_limits当前密钥的累计 token 上限与累计请求数上限，以及已用量和剩余量。未设置上限的项返回 null；没有设置上限时，已用量最多有约 60 秒的延迟。
recent_usage.data当前密钥最近的调用记录，按时间倒序。只包含这一把密钥的记录，不包含同账户其他密钥的记录。
prompt_tokens / completion_tokens该次调用的输入与输出 token 数。
status_code该次调用的状态码。
cost该次调用的实际扣费，单位为元，已包含缓存折扣。免费模型为 0；请求仍在结算中时为 null，求和时请跳过。
created_at调用时间，ISO 8601 格式（UTC）。

调用限制与安全

  • 每个账户每分钟最多查询 30 次，超出时返回 429 rate_limit_exceeded，按 Retry-After（60 秒）等待。
  • 余额服务暂时不可用时返回 503 service_unavailable，稍后重试。
  • 响应带 Cache-Control: no-store，不要在中间层缓存它。

任何持有密钥的人都能查询账户余额。不要把密钥交给不应看到余额的人。

每次响应中的 usage

每个推理响应都带有本次调用的 token 用量，适合按功能或用户汇总：

协议字段
Chat Completionsusage.prompt_tokens、completion_tokens、total_tokens，推理模型另有 completion_tokens_details.reasoning_tokens
Responsesusage.input_tokens、output_tokens、total_tokens
Messagesusage.input_tokens、output_tokens

流式请求的 usage 在流的结尾返回。usage 不包含缓存命中的 token 数，实际扣费以 cost 为准。

在控制台查看

控制台的用量页可以查看最近 30 天所有个人密钥的调用记录、token 用量与消费金额；账单页可以查看余额与充值记录。团队的用量在团队页查看。
