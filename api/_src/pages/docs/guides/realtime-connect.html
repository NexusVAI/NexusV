--- title: 连接与认证 description: 建立 WebSocket 连接、传递 API 密钥，并用 Node.js、Python 或浏览器跑通第一个语音会话。 tab: realtime ---

实时语音使用一条长连接的 WebSocket。认证、账户状态和速率限制都在握手时检查；握手成功后，你在同一条连接上收发 JSON 事件，直到会话结束。

端点

GET wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions

实时语音只能连接 chat.nexusvai.xyz。cn.nexusvai.xyz 不转发 WebSocket 升级请求，连接会返回 426 websocket_required。其他 HTTP 接口可以继续使用 cn.nexusvai.xyz。

传递 API 密钥

服务端程序把 Key 放在请求头里。浏览器的 WebSocket 不能自定义请求头，改用子协议传递。Key 必须以 cancri_sk_ 开头。

方式写法适用
请求头（推荐）Authorization: Bearer cancri_sk_...，或 x-api-key: cancri_sk_...Node.js、Python、Go 等服务端程序
WebSocket 子协议openai-insecure-api-key.cancri_sk_...，别名 cancri-key.cancri_sk_...浏览器

用子协议传 Key 时，再附带一个普通子协议（例如 cancri-live）。服务端会选用这个普通子协议回应握手，Key 就不会出现在响应头里：

const ws = new WebSocket(url, ["cancri-live", "openai-insecure-api-key." + key]);

不要把正式 Key 写进公开网页。浏览器直连只适合本地调试。上线时，让浏览器连接你自己的服务端，由服务端持有 Key 并连接 NexusVAI；或者在控制台为前端单独创建一个 Key，把模型白名单设为只含 gpt-live-1，并设置累计额度上限。

Key 的模型限制

  • Key 设置了模型白名单时，白名单必须包含 gpt-live-1，否则握手返回 403 model_not_in_whitelist。用站内模型做后端时，该模型也要在白名单里，因为后端调用使用同一个 Key。
  • 绑定了模型分组的 Key 不能用于实时语音，握手返回 403 model_not_in_group。请另建一个不绑定分组的 Key。
  • Key 的累计 token 或请求次数上限已用完时，握手返回 429（key_token_quota_exhausted 或 key_request_quota_exhausted）。累计额度只在建立连接时检查。

会话流程

  1. 建立 WebSocket 连接。未通过检查时，握手直接返回 HTTP 错误，见握手错误。
  2. 在 20 秒内发送第一条事件 session.start。超时会收到 session_start_timeout 错误，随后连接关闭。
  3. 服务端预扣第一段（30 秒）语音费，再连接上游。余额不足时收到 insufficient_balance 错误并断开，不产生费用。
  4. 收到 session.started 和 cancri.session.created 后，开始持续发送 session.input_audio.append。
  5. 结束时发送 session.close，等待 session.closed（包含最终计费秒数）和 cancri.billing.updated（final: true）。

在 session.started 之前发出的事件会先排队，会话开始后按顺序转发。队列最多保留 200 条，超出的事件会被丢弃。

快速开始

下面的服务端示例读取一个 24 kHz、单声道、16 位的 PCM WAV 文件，按实时速度每 100 ms 发送一块，打印双向转写，结束时输出本次费用。运行前先安装依赖（Node.js：npm i ws；Python：pip install websockets），并设置环境变量 CANCRI_API_KEY。

import WebSocket from "ws";
import { readFileSync, writeFileSync } from "node:fs";

const URL = "wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions";
const ws = new WebSocket(URL, { headers: { Authorization: `Bearer ${process.env.CANCRI_API_KEY}` } });

const pcm = readFileSync("question.wav").subarray(44); // 跳过 44 字节的 WAV 头
const out = [];

ws.on("open", () => {
  ws.send(JSON.stringify({
    type: "session.start",
    session: {
      model: "gpt-live-1",
      instructions: "你是一个简洁的中文语音助手。",
      audio: { format: { type: "audio/pcm", rate: 24000 }, output: { voice: "marin" } },
      // 不写 delegation：使用默认的 GPT-6-Luna 官方后端
    },
  }));
});

ws.on("message", async (buf) => {
  const e = JSON.parse(buf.toString());
  switch (e.type) {
    case "session.started": {
      for (let i = 0; i < pcm.length; i += 4800) { // 4800 字节 = 100 ms
        ws.send(JSON.stringify({
          type: "session.input_audio.append",
          audio: pcm.subarray(i, i + 4800).toString("base64"),
        }));
        await new Promise((r) => setTimeout(r, 100));
      }
      setTimeout(() => ws.send(JSON.stringify({ type: "session.close" })), 15000);
      break;
    }
    case "session.output_audio.delta": out.push(Buffer.from(e.delta, "base64")); break;
    case "session.input_transcript.delta": process.stdout.write(`[你] ${e.delta}\n`); break;
    case "session.output_transcript.delta": process.stdout.write(`[AI] ${e.delta}\n`); break;
    case "cancri.billing.updated": if (e.final) console.log("本次费用 ¥", e.total_cny, "计费秒数", e.seconds); break;
    case "error": console.error("error", e.error); break;
  }
});

ws.on("close", (code, reason) => {
  writeFileSync("answer.pcm", Buffer.concat(out)); // 24 kHz、16 位、单声道的裸 PCM
  console.log("closed", code, reason.toString());
});
import asyncio, base64, json, os, websockets

URL = "wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions"

async def main():
    headers = {"Authorization": f"Bearer {os.environ['CANCRI_API_KEY']}"}
    async with websockets.connect(URL, additional_headers=headers, max_size=None) as ws:
        await ws.send(json.dumps({
            "type": "session.start",
            "session": {
                "model": "gpt-live-1",
                "audio": {"format": {"type": "audio/pcm", "rate": 24000}},
                "delegation": {"type": "responses", "responses": {
                    "model": "gpt-6-luna",
                    "tools": [{"type": "web_search"}],
                }},
            },
        }))
        pcm = open("question.wav", "rb").read()[44:]  # 跳过 44 字节的 WAV 头
        async for raw in ws:
            e = json.loads(raw)
            if e["type"] == "session.started":
                async def pump():
                    for i in range(0, len(pcm), 4800):  # 4800 字节 = 100 ms
                        await ws.send(json.dumps({"type": "session.input_audio.append",
                                                  "audio": base64.b64encode(pcm[i:i+4800]).decode()}))
                        await asyncio.sleep(0.1)
                    await asyncio.sleep(15)
                    await ws.send(json.dumps({"type": "session.close"}))
                asyncio.create_task(pump())
            elif e["type"].endswith("transcript.delta"):
                print(e["type"], e["delta"])
            elif e["type"] == "cancri.billing.updated" and e["final"]:
                print("本次费用 ¥", e["total_cny"])
            elif e["type"] == "error":
                print("error", e["error"])

asyncio.run(main())

静音也是音频。真实对话里，麦克风会持续发送音频帧，模型据此判断你什么时候说完。如果只发一段录音就停止，模型可能一直在等你继续说。所以示例发完录音后停止发帧，15 秒后用 session.close 结束会话。

Python 的 websockets 从 14 版开始使用 additional_headers 参数，旧版本叫 extra_headers。

在浏览器中调试

下面的示例采集麦克风并播放回复。Key 直接写在页面里，只能用于本地调试。

const KEY = "cancri_sk_..."; // 仅用于本地调试，见上方的安全提示
const URL = "wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions";
const ctx = new AudioContext({ sampleRate: 24000 });
let playAt = 0;

const ws = new WebSocket(URL, ["cancri-live", "openai-insecure-api-key." + KEY]);
ws.onopen = () => ws.send(JSON.stringify({
  type: "session.start",
  session: { model: "gpt-live-1", audio: { format: { type: "audio/pcm", rate: 24000 } } },
}));

ws.onmessage = async (ev) => {
  const e = JSON.parse(ev.data);
  if (e.type === "session.started") startMic();
  if (e.type === "session.output_audio.delta") play(e.delta);
  if (e.type === "error") console.error(e.error);
};

async function startMic() {
  const stream = await navigator.mediaDevices.getUserMedia({
    audio: { channelCount: 1, echoCancellation: true },
  });
  const src = ctx.createMediaStreamSource(stream);
  const proc = ctx.createScriptProcessor(2048, 1, 1); // 上下文已是 24 kHz，无需重采样
  proc.onaudioprocess = (ev) => {
    const f32 = ev.inputBuffer.getChannelData(0);
    const i16 = new Int16Array(f32.length);
    for (let i = 0; i < f32.length; i++) i16[i] = Math.max(-1, Math.min(1, f32[i])) * 0x7fff;
    if (ws.readyState === 1) {
      ws.send(JSON.stringify({ type: "session.input_audio.append", audio: b64(i16.buffer) }));
    }
  };
  src.connect(proc); proc.connect(ctx.destination);
}

function play(b64data) {
  const bytes = Uint8Array.from(atob(b64data), (c) => c.charCodeAt(0));
  const i16 = new Int16Array(bytes.buffer);
  const buf = ctx.createBuffer(1, i16.length, 24000);
  const ch = buf.getChannelData(0);
  for (let i = 0; i < i16.length; i++) ch[i] = i16[i] / 0x8000;
  const node = ctx.createBufferSource();
  node.buffer = buf; node.connect(ctx.destination);
  playAt = Math.max(playAt, ctx.currentTime); node.start(playAt); playAt += buf.duration;
}

function b64(ab) {
  let s = "";
  const u8 = new Uint8Array(ab);
  for (let i = 0; i < u8.length; i += 0x8000) {
    s += String.fromCharCode.apply(null, u8.subarray(i, i + 0x8000));
  }
  return btoa(s);
}
  • 浏览器要求用户先与页面交互，才允许播放声音。可以在点击事件里调用 ctx.resume()。
  • 生产环境建议改用 AudioWorklet 处理音频，并在用户打断时清空播放队列。
