使用 NexusVAI API，你可以调用大语言模型生成自然语言文本、代码或 JSON 数据。下面用 Responses API 演示如何发送提示词并读取回复。

先创建 API 密钥并将其设为 CANCRI_API_KEY。Python 和 Node.js 示例使用兼容的 openai SDK，请按SDK 指南安装。

import OpenAI from "openai";

const apiKey = process.env.CANCRI_API_KEY;
if (!apiKey) throw new Error("请先设置 CANCRI_API_KEY");
const client = new OpenAI({
  baseURL: "https://cn.nexusvai.xyz/v1",
  apiKey,
});

const response = await client.responses.create({
  model: "gpt-6-astra",
  input: "用一句话写一个关于独角兽的睡前故事。",
});
console.log(response.output_text);
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://cn.nexusvai.xyz/v1",
    api_key=os.environ["CANCRI_API_KEY"],
)
response = client.responses.create(
    model="gpt-6-astra",
    input="用一句话写一个关于独角兽的睡前故事。",
)
print(response.output_text)
curl https://cn.nexusvai.xyz/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $CANCRI_API_KEY" \
  -d '{
    "model": "gpt-6-astra",
    "input": "用一句话写一个关于独角兽的睡前故事。"
  }'

Responses 的 output 是一个数组，可能同时包含消息、工具调用和推理摘要。不要假设文本总在 output[0]。Python 和 Node.js SDK 提供 output_text，可直接取得拼接后的文本；通过 HTTP 读取时，遍历 output 中的消息及其 output_text 内容块。

如果应用需要机器可读的数据，请参阅结构化输出，并在应用中校验模型返回的内容。

提示词工程

把任务、约束和期望输出写清楚。比如与其说「改写这段话」，不如说「面向新用户改写这段话，不超过 100 字，保留所有专有名词」。复杂任务可以补上一两个示例。升级模型或改动提示词前，先用一组有代表性的输入比较输出。更多方法见提示词工程。

选择模型与 API

先从模型目录选出符合能力、延迟和预算要求的模型，用 GET /v1/models 确认可用 ID。

  • 如果需要 input、instructions 和按类型区分的输出项，使用 Responses。
  • 如果现有客户端使用 messages 和 choices，继续用 Chat Completions。

消息角色与指令遵循

在 Responses 请求中，把应用的任务规则或回复风格放进 instructions，把用户内容放进 input。单轮输入可以直接用字符串；多轮输入用数组保存 user 和 assistant 消息。

{
  "model": "gpt-6-astra",
  "instructions": "用简体中文回答，不超过两句话。",
  "input": [
    {"role": "user", "content": "什么是 API？"},
    {"role": "assistant", "content": "API 是软件之间约定的调用方式。"},
    {"role": "user", "content": "请举一个生活中的类比。"}
  ]
}

NexusVAI API 不在服务端保存 Responses 对话状态。不要只传 previous_response_id；每轮都要带上所需历史和适用的 instructions。见多轮对话。

在代码中管理提示词版本

把生产提示词与应用代码一起版本化。将固定指令和动态参数分开，记录代表性测试用例，并在修改提示词或模型时重跑。NexusVAI API 不支持托管提示词 ID；已有的提示词对象可按迁移指南改成内联消息。
