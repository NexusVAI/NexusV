在 Cancri Code 的「设置 → 搜索、图片识别与语音」中，可以分别选择搜索引擎和语音识别服务，两项默认都是 DeepSeek API。图片识别选的是何时提取文字，朗读选的是在线还是本机合成，这两项没有单独的 NexusVAI 云服务选项。

以下均为人民币。DeepSeek 一列是官方非促销刊例价；通过桌面端使用时，平台按刊例价加 5%，得到最右列的桌面基价。该列已含这 5%，不会重复加收。

这些是工具费。模型阅读搜索结果、理解原图或处理识别出的文字，另按所选模型的价格计费。即使为聊天配置了自己的模型密钥，桌面内置在线工具仍使用已登录的 Cancri 账户。通过公开 /v1 接口自行实现和执行的工具，不适用本表。

一次操作怎样计量

  • 搜索：一次 DeepSeek 搜索返回一条或多条有效结果，都只计一次；没有结果或请求失败，不收搜索费。
  • 图片：一张成功处理的图片计一页，不按识别出的字数收费。有效页面没有文字或文字因长度限制而截断，仍计一页。「仅文字模型自动 OCR」只在已知模型不能看图时触发；「不自动 OCR」不影响你单独批准的手动识别。直接发给视觉模型不产生 OCR 页费。
  • 语音输入：DeepSeek 按每段实际识别的音频时长向上取整到秒，例如 5.2 秒按 6 秒计量，不按识别出的字数计。它会自动识别语种；需要指定普通话、粤语等语种时，选择 NexusVAI API。
  • 朗读：在线合成按段计量，汉字按 2 个计费字符，其余 Unicode 码点按 1 个。已经成功合成的段落即使停止播放仍计费，以后没有合成的段落不计费。选择本机语种和音色时，文字不上传，不消耗额度。

套餐倍率与钱包扣款

套餐扣额 = 工具用量 × 桌面基价 × 套餐倍率。下表的「多扣」是相对桌面基价而言，指套餐额度消耗，不是在月费之外再收一笔现金。免费的工具不因倍率而变成收费项目。

例如，DeepSeek 一次有结果的搜索，桌面基价为 ¥0.00525。Pro 套餐额度充足时，这次扣 ¥0.0168 套餐额度，钱包扣 ¥0；若有效 Pro 套餐的额度已用完，这次改扣 ¥0.004725 钱包余额。若额度只够支付一部分，只有差额转入钱包，钱包部分不再乘套餐倍率。

这是套餐的正常定价方式。以 Pro 为例，¥99 购买的是每月 ¥300 的套餐计量额度，不是充值 ¥300 钱包余额，不能按 ¥300 现金原价购买工具服务。当前桌面付费工具需要有效套餐；预扣无法覆盖本次请求时，不会开始付费调用。公开 API 余额和桌面套餐的区别见计费与余额。
