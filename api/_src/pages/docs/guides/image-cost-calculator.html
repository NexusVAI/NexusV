使用计算器

  1. 选择你计划使用的视觉模型。
  2. 输入图片原始的宽高（像素）。计算器会按该模型的缩放规则处理。
  3. 选择该模型支持的图片细节等级。
  4. 查看图片输入 token 数和估算费用。如果处理后的图片超过 30,000 个 patch 的上限，计算器会显示拒绝提示而不给出估算。展开计算详情可查看缩放后的尺寸和 token 计算过程。

例如，一张 6000 × 6000 的图片在 gpt-6-astra 上使用 original 细节时超出上限（35,344 个 patch），但使用 high 细节缩放后可以放下（2,500 个 patch）。只有当任务不需要原始分辨率或精确的图像坐标时，才选择 high。

理解估算结果

估算按标准输入价格计算一张图片的费用。不包括其他提示词 token、模型输出、缓存、长上下文定价和数据驻留调整。由于取整，实际计费可能相差一个 token。

缩放和 token 化规则见图片输入费用计算。当前模型费率和其他费用见 API 价格。
