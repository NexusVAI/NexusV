计算详情

单次费用 =（输入 − 缓存命中）× 输入单价 + 缓存命中 × 输入单价 × 缓存系数 + 输出 × 输出单价，单价按每百万 token 计。总费用 = 单次费用 × 请求次数。

按次计费的模型只按请求次数计算；免费模型不扣余额。

实际扣费以用量记录为准。估算不含 Anthropic 协议的缓存写入（按输入价 1.25 倍计）。

使用计算器

  1. 选择要调用的模型。列表按厂商分组，与模型目录一致；免费和按次计费的模型会在名称后标明。
  2. 填入一次请求的输入 token 和输出 token。输入里命中提示缓存的部分填到「其中缓存命中」，它不能超过输入 token。
  3. 需要估算批量调用时，填入请求次数。token 数较大时可以把单位切换为「千」或「百万」，已填的数会自动换算。
  4. 查看估算总费用和单次请求费用。展开计算详情可以看到单价和每一项的费用。

例如，一次请求输入 10,000 token、其中 8,000 token 命中缓存、输出 2,000 token：未命中的 2,000 token 按输入价计费，8,000 token 按缓存命中价计费，再加上 2,000 token 的输出费用。

理解估算结果

计算器使用与结算相同的公式。缓存命中默认按输入价的 1 折计费，少数模型例外，例外的系数会显示在计算详情里。实际 token 数以上游返回的用量为准，与本地估算可能不同。

站内实际费用请用模型定价与用量记录核对。
