SillyTavern 支持自定义的 OpenAI 兼容端点。选择 Chat Completion 类型的 API 并填入 NexusVAI 的地址，就能在角色对话中使用 NexusVAI 的模型。

前提条件

  • 已启动 SillyTavern，并能打开它的网页界面。
  • 一个 NexusVAI API 密钥，可以在控制台创建。

配置 API 连接

  1. 在网页界面顶部点击 API 连接（插头图标）。
  2. API 下拉菜单选择 Chat Completion。
  3. Chat Completion Source 选择 Custom (OpenAI-compatible)，按下表填写。
  4. 点击 Connect。
  5. 连接成功后，在 Model 下拉列表中选择模型 ID，例如 gpt-6-astra、claude-opus-5.5 或 deepseek-v4-flash。
设置项值
Custom Endpointhttps://cn.nexusvai.xyz/v1
API Keycancri_sk_...

不同模型适合的 Prompt 格式不同，切换模型后可以相应调整 SillyTavern 的 Prompt 预设。

验证配置

点击 Connect 后能看到模型列表，说明地址和 Key 有效；再发送一条消息并收到回复，说明所选模型可用。要核对这次调用的扣费，可以查询 GET /v1/balance，见验证请求是否到达 NexusVAI。

排查问题

现象可能的原因解决方法
Connect 失败Custom Endpoint 与上表不一致。填 https://cn.nexusvai.xyz/v1。
发送消息报 401Key 填错或已撤销。在控制台确认 Key 状态。
404 model_not_found选择的模型不在 GET /v1/models 的列表中。重新连接后从列表中选择。
