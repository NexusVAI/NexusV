--- title: Cursor description: 用 Override OpenAI Base URL，在 Cursor 的对话中使用 NexusVAI 的模型。 tab: coding ---

Cursor 允许覆盖 OpenAI 的 Base URL。开启后，Cursor 会用你的 API 密钥和自定义地址调用 NexusVAI 的模型。对话、Agent、Composer 和行内补全是否使用这个地址，取决于 Cursor 的版本。

前提条件

  • 已安装 Cursor。
  • 一个 NexusVAI API 密钥，可以在控制台创建。
  • 要使用的模型 ID，例如 gpt-6-astra 或 claude-opus-5.5。

配置自定义 Base URL

  1. 打开 Settings → Models，找到 OpenAI API Key。
  2. 填入你的 API 密钥，并开启 Override OpenAI Base URL。
  3. 按下表填写，然后手动添加要用的模型 ID。
设置项值
Override URLhttps://cn.nexusvai.xyz/v1
API Keycancri_sk_...
ModelNexusVAI 模型 ID，例如 gpt-6-astra、claude-opus-5.5

自定义地址通常只对对话生效。Agent、Composer 和行内补全可能仍然使用 Cursor 自己的服务，对话能用不代表所有功能都已切换。需要可以自定义 Base URL 的编程智能体时，推荐使用 Claude Code、Cline 或 Continue。

验证配置

在 Cursor 的对话里选择你添加的模型，发送一条简短的消息。然后查询这个 Key 最近的调用：

curl "https://cn.nexusvai.xyz/v1/balance?limit=5" \
  -H "Authorization: Bearer cancri_sk_..."

如果 recent_usage.data 里出现了这次请求，说明对话已经走 NexusVAI。用同样的方法检查 Agent 或补全：使用后没有新增记录，就说明那个功能没有使用自定义地址。字段说明见验证请求是否到达 NexusVAI。

排查问题

现象可能的原因解决方法
对话正常，但 Agent 或补全没有调用记录该功能不使用自定义 Base URL。改用 Claude Code、Cline 或 Continue。
404 model_not_found模型 ID 与 GET /v1/models 不一致，或被客户端改写。手动填入列表中的 id。
401 invalid_api_keyKey 填错或已撤销。在控制台确认 Key 状态。
