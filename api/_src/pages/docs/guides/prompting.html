提示词是你发送给模型的任务说明、示例与上下文。使用 NexusVAI API 时，把稳定的规则和每次变化的用户输入分开，便于维护、测试，也便于比较不同模型的效果。

概览

先说明任务目标、输入边界和期望输出。对于不确定的情况，明确模型应该追问、回答「信息不足」，还是返回一个可供程序检查的状态。

提示工具与技巧

  • 提示缓存：把可复用的固定前缀放在开头，变化的输入放在后面；是否命中取决于模型和请求。
  • 提示词工程：用任务约束、示例和上下文提高结果的稳定性。
  • 结构化输出：把字段要求写成 JSON Schema，并在应用侧验证。

优化你的提示词

  • 在 Responses 的 instructions 或 Chat Completions 的 system 消息中写整体规则，在用户输入中提供本轮任务和材料。
  • 用清楚的标签或分段区分示例、参考资料和指令。
  • 每次只改一个关键设置，用一组代表性输入比较升级前后的输出。

在应用中使用提示词

NexusVAI API 不支持托管的提示词 ID。把提示词存进应用的版本控制，用函数参数填入动态值，再将结果作为 instructions 和 input 发送给 Responses API。

现有集成如果使用提示词对象，可按迁移指南转成内联请求。

后续步骤
