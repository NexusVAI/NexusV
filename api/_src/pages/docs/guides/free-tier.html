--- title: 免费模型与免费额度 description: 免费模型不扣余额，但计入每个账户每 24 小时 1 亿 token 的免费额度，并受速率限制约束。 ---

在模型中标为免费的模型，可以直接用普通的 cancri_sk_ 密钥调用，不扣余额，也无需申请。免费模型的调用计入账户的免费额度，同时和付费模型一样受速率限制约束。

哪些模型免费以模型页为准。GET /v1/models 的返回不标注价格或是否免费。

免费额度

项目说明
额度每个账户每 24 小时 100,000,000 token（1 亿），显示为 10,000 积分（1 积分 = 1 万 token）。
计入方式输入与输出 token 合计。只有免费模型的调用计入，付费模型不占用免费额度。
周期滚动 24 小时，从周期外的第一次使用开始计时。周期结束后不会自动开始新周期，下一次使用时才重新计时。
共享范围同一账户的网页、桌面端、Bot 与 API 共用。
不受限制的账户有有效套餐的账户，或累计充值达到 ¥10 的账户。这些账户的 RPM 与 TPM 仍然生效。

额度用完时

额度用完后，调用免费模型返回 429 free_plan_exhausted。这个错误不可重试：响应带 x-should-retry: false，不带 Retry-After，官方 SDK 不会自动重试。错误对象里的额外字段告诉你什么时候恢复：

{
  "error": {
    "type": "rate_limit_error",
    "message": "免费计划 24 小时额度（10,000 积分）已用完，将于 2026-11-08 12:30（UTC+8）重置。开通套餐可解除限制。",
    "code": "free_plan_exhausted",
    "resets_at": "2026-11-08T04:30:00.000Z",
    "limit_tokens": 100000000,
    "used_tokens": 100004096,
    "retry_after_seconds": 41250
  }
}
字段说明
resets_at额度重置时间，ISO 8601 格式（UTC）。
limit_tokens周期额度，单位 token。
used_tokens本周期已用量，单位 token。
retry_after_seconds距离重置还有多少秒。

在 /v1/messages 上，同样的字段位于 Anthropic 格式的 error 对象中。

解除限制

累计充值达到 ¥10，或开通套餐后，免费模型不再受免费额度限制。充值与套餐见控制台的账单页。

团队密钥

用团队密钥调用免费模型时，用量计入持有这把密钥的成员自己的免费额度，不会因为建了团队而多出一份额度。团队累计划转到团队余额的金额达到 ¥10 后，团队密钥不再受免费额度限制。见团队。

不对 API 开放的免费模型

  • 桌面端专属的免费模型只在 Cancri Code 中可用，通过 API 调用返回 403 model_ide_only。
  • 限时开放的免费模型过了访问期后不再可用，调用返回 404 model_not_found。

上下文长度

上下文长度与最大输出 token 数按模型而定，见模型页的模型卡片。输入超过模型上限时请求会失败，请缩短上下文或换用上下文更长的模型。
