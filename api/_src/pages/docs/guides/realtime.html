gpt-live-1 是 OpenAI 的全双工实时语音模型。你持续发送麦克风音频，模型一边听一边说，同时返回你和它的转写文本。NexusVAI 通过 WebSocket 提供这个模型，事件格式与 OpenAI Live 协议一致：沿用现有的 Live 客户端代码，换成 NexusVAI 的地址和 API 密钥即可。

工作方式

gpt-live-1 负责听和说。遇到需要推理、查资料或调用工具的问题，它把任务委派给一个后端，拿到结果后再用自己的话说出来。你在 session.start 的 delegation 字段里选择后端：

后端模式怎么配置谁来回答适合
官方后端（默认）省略 delegation，或把 delegation.responses.model 设为 gpt-6-lunaOpenAI GPT-6-Luna。未指定 tools 时默认启用联网搜索，也可以加入你自己的函数工具开箱即用的语音助手
站内模型把 delegation.responses.model 设为 GET /v1/models 中的任意模型，例如 claude-haiku-5.5你选的站内模型需要特定模型的能力或口吻
只买语音层把 delegation.type 设为 "client"你自己的程序或 Agent已有 Agent，只缺语音交互

每种模式的完整参数见会话与后端模式。

一次会话的流程

  1. 用 WebSocket 连接 wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions，握手时带上 API 密钥。
  2. 在 20 秒内发送第一条事件 session.start。
  3. 服务端预扣第一段 30 秒的语音费，然后连接上游。
  4. 收到 session.started 和 cancri.session.created 后，持续发送 session.input_audio.append。
  5. 同时接收回复音频（session.output_audio.delta）和双向转写。
  6. 发送 session.close，等待 session.closed 和最终账单 cancri.billing.updated（final: true）。

价格

暂不支持

  • WebRTC 接入：只能使用 WebSocket。
  • cn.nexusvai.xyz：实时语音只能连接 chat.nexusvai.xyz，其他 HTTP 接口不受影响。
  • 其他官方后端模型：官方后端只提供 GPT-6-Luna，也不支持 Fast / priority 档。delegation.responses.model 填其他 id 时，会按站内模型处理。
  • Decisions：不支持 delegation.type = "decisions" 和非空的 triggers。
  • 会话存储与录音下载：store 只能为 false。
  • 容器类工具：代码解释器、shell、图像生成等不可用。官方后端只接受 web_search、function 和 custom 三类工具。

gpt-live-1 只能通过这个 WebSocket 端点使用：它不在 GET /v1/models 的列表里，也不能用于 /v1/chat/completions 等 HTTP 端点。
