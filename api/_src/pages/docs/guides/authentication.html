--- title: 认证与 API 密钥 description: 用 API 密钥认证每个请求，并为每把密钥设置合适的权限与限额。 ---

NexusVAI API 用 API 密钥认证请求。每个请求都要带上一把以 cancri_sk_ 开头的密钥；同一把密钥可以调用 OpenAI 协议和 Anthropic 协议的全部端点。

在请求中携带密钥

以下两种请求头任选其一：

请求头写法常见用法
AuthorizationBearer cancri_sk_...OpenAI SDK、大多数 OpenAI 兼容工具
x-api-keycancri_sk_...Anthropic SDK、Claude Code
 
curl https://cn.nexusvai.xyz/v1/balance \
  -H "Authorization: Bearer $CANCRI_API_KEY"
curl https://cn.nexusvai.xyz/v1/balance \
  -H "x-api-key: $CANCRI_API_KEY"

两个请求头同时出现时，以 Authorization 为准。使用官方 SDK 时只需把密钥传给 api_key（或 apiKey），SDK 会选择正确的请求头。

密钥格式

密钥由前缀 cancri_sk_（10 个字符）和 48 个 base64url 字符组成，总长 58 个字符。后 48 位只包含 A-Z、a-z、0-9、- 和 _，没有 +、/ 或 =。

在客户端校验格式时，可以使用这个正则表达式：

^cancri_sk_[A-Za-z0-9_-]{48}$

不以 cancri_sk_ 开头的值会直接返回 401 invalid_api_key。

创建与管理密钥

在控制台的 API 密钥页创建、查看和撤销密钥。

  • 完整密钥只显示一次。创建后立即复制保存；之后页面只显示前缀，无法找回完整密钥。
  • 每个账户最多 5 把有效密钥。达到上限后，先撤销旧密钥再创建。团队密钥另计，不占个人名额，见团队。
  • 每个账户每小时最多创建 10 把密钥。
  • 撤销立即生效，且不可恢复。已撤销的密钥会返回 401 invalid_api_key。

速率限制按账户计算，多建几把密钥不会提高限额。见速率限制。

密钥级限制

创建密钥时可以指定一个模型分组，这把密钥就只能调用该分组内的模型。把不同的应用或环境分到不同的密钥上，一把密钥出问题时影响范围最小。

密钥上还可能带有以下限制。触发时的响应如下：

限制说明触发时的响应
模型分组只允许调用指定分组内的模型403 model_not_in_group
模型白名单最多 50 个模型 ID，按 ID 精确匹配403 model_not_in_whitelist
累计 token 上限这把密钥累计可用的 token 总数429 key_token_quota_exhausted
累计请求数上限这把密钥累计可发的请求总数429 key_request_quota_exhausted
RPM 上限1–600，只能比账户档位更严429 rate_limit_exceeded，error.scope 为 key

累计上限不会自动重置。用 GET /v1/balance 可以查看当前密钥的已用量和剩余量；上限用完后，请改用其他密钥或创建一把新密钥。

密钥的适用范围

cancri_sk_ 密钥只能调用 /v1/* 接口。网页版对话、账户设置与订单使用登录会话，不接受 API 密钥；反过来，浏览器的登录 Cookie 或登录令牌也不能代替 API 密钥。

账户被限制使用时，该账户名下的全部密钥都会返回 403 account_suspended。

保护你的密钥

任何拿到密钥的人都能以你的名义调用 API、消耗你的余额，并通过 GET /v1/balance 看到账户余额。

  • 只在服务端使用密钥。把密钥放在服务端的环境变量或密钥管理服务中，从你自己的后端发起请求。API 的跨域访问只对 NexusVAI 自己的网站开放，第三方网页在浏览器里直接调用会被浏览器拦截。
  • 不要提交到代码仓库。不要把密钥写进源码、配置文件或公开的 Issue 与日志。
  • 一个用途一把密钥。按应用或环境分开创建，并按需设置上面的限制，便于单独撤销。
  • 发现泄露立即撤销。在 API 密钥页撤销该密钥，创建新密钥并更新配置。

认证错误

HTTPerror.code原因与处理
401invalid_api_key缺少密钥、格式错误、密钥不存在或已撤销。检查请求头与密钥本身，不要重试。
403account_suspended账户已被限制使用。如果你认为有误，请联系我们。
429auth_rate_limited同一 IP（IPv6 按 /64 网段计算）在短时间内多次使用不存在的密钥：每分钟超过 20 次或每小时超过 100 次。按 Retry-After 等待，并修正客户端里的密钥配置。
503service_unavailable认证服务暂时不可用，与你的密钥无关。稍后重试。

完整列表见错误码。
