用 NexusVAI API 可以编写和解释代码、用样例检查逻辑，以及按项目约束生成修改建议。你可以接入已有编程工具，也可以从自己的应用发起请求。

开始使用

把终端编程工具连接到 NexusVAI API。 通过 Responses API 发送代码和修改要求。

使用 Codex

在 Codex CLI 配置中使用自定义服务，填入 NexusVAI Base URL、API 密钥和模型目录中的 ID。完整步骤见 Codex CLI 接入指南。

与编程模型集成

下面用 Responses API 审查一小段代码。实际项目还可在输入中加入目录结构、测试输出或需要保持的现有行为。先按快速开始设置 CANCRI_API_KEY。

import os
from openai import OpenAI

client = OpenAI(base_url="https://cn.nexusvai.xyz/v1", api_key=os.environ["CANCRI_API_KEY"])
response = client.responses.create(
    model="gpt-6-astra",
    instructions="用中文指出问题，并给出一个可验证的测试用例。",
    input="审查：def average(nums): return sum(nums) / len(nums)",
)
print(response.output_text)

使用 Codex

Codex 是 OpenAI 面向软件开发的编程智能体，可以帮助你编写、审查和调试代码。你可以在 IDE、命令行、网页和移动端中使用它，也可以借助 SDK 在 CI/CD 流水线中调用。若想在项目中落地智能体式的软件工程，Codex 是最好的选择。

Codex 最适合搭配最新的通用模型，例如 gpt-6.1-sol。

设置指南、参考资料、价格等更多信息，请参阅 ChatGPT 文档。

与编程模型集成

大多数基于 API 的代码生成场景，可以从 gpt-6-astra 开始。它兼顾通用任务和编程任务，当你的应用需要编写代码、推理需求、查阅文档，并在一处处理更广泛的工作流时，它是很好的默认选择。

下面的示例展示如何在代码生成场景中使用 Responses API：

from openai import OpenAI

client = OpenAI()

result = client.responses.create(
    model="gpt-6-astra",
    input="""Find the null pointer exception in this code:

def display_name(user):
    return user.profile.name

print(display_name(None))
""",
    reasoning={"effort": "high"},
)

print(result.output_text)

package main

import (
	"context"
	"fmt"

	"github.com/openai/openai-go/v3"
	"github.com/openai/openai-go/v3/responses"
	"github.com/openai/openai-go/v3/shared"
)

func main() {
	client := openai.NewClient()
	response, err := client.Responses.New(context.Background(), responses.ResponseNewParams{
		Model: "gpt-6-astra",
		Input: responses.ResponseNewParamsInputUnion{OfString: openai.String(`Find the null pointer exception in this code:

def display_name(user):
    return user.profile.name

print(display_name(None))`)},
		Reasoning: shared.ReasoningParam{Effort: shared.ReasoningEffortHigh},
	})
	if err != nil {
		panic(err)
	}
	fmt.Println(response.OutputText())
}
import com.openai.client.OpenAIClient;
import com.openai.client.okhttp.OpenAIOkHttpClient;
import com.openai.models.Reasoning;
import com.openai.models.ReasoningEffort;
import com.openai.models.responses.ResponseCreateParams;

String code =
    """
    def display_name(user):
        return user.profile.name

    print(display_name(None))
    """;

ResponseCreateParams params =
    ResponseCreateParams.builder()
        .model("gpt-6-astra")
        .input("Find the null pointer exception in this code:\n\n" + code)
        .reasoning(Reasoning.builder().effort(ReasoningEffort.HIGH).build())
        .build();

client.responses().create(params).output().stream()
    .flatMap(item -> item.message().stream())
    .flatMap(message -> message.content().stream())
    .flatMap(content -> content.outputText().stream())
    .forEach(text -> System.out.println(text.text()));
using OpenAI.Responses;
#pragma warning disable OPENAI001

string key = Environment.GetEnvironmentVariable("OPENAI_API_KEY")!;
ResponsesClient client = new(key);

CreateResponseOptions options = new()
{
    Model = "gpt-6-astra",
    ReasoningOptions = new ResponseReasoningOptions
    {
        ReasoningEffortLevel = ResponseReasoningEffortLevel.High,
    },
};
options.InputItems.Add(
    ResponseItem.CreateUserMessageItem(
        """
        Find the null pointer exception in this code:

        def display_name(user):
            return user.profile.name

        print(display_name(None))
        """
    )
);

ResponseResult response = await client.CreateResponseAsync(options);
Console.WriteLine(response.GetOutputText());
