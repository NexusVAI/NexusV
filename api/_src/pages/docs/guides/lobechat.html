LobeChat 支持 OpenAI 兼容端点，可以通过 OpenAI 模块或自定义 OpenAI 模块接入 NexusVAI。

前提条件

  • 可以使用的 LobeChat。
  • 一个 NexusVAI API 密钥，可以在控制台创建。

配置语言模型

  1. 打开 LobeChat，点击左下角的头像，进入 设置。
  2. 选择 语言模型 标签。
  3. 展开 OpenAI 或 自定义 OpenAI 模块，打开开关，按下表填写。
  4. 检查通过后，在模型列表中选择 NexusVAI 的模型。
设置项值
API 密钥cancri_sk_...
接口代理地址 / Base URLhttps://cn.nexusvai.xyz/v1

如果模型列表没有刷新，手动输入 GET /v1/models 返回的模型 ID。

验证配置

选择一个 NexusVAI 模型并发送一条简短的消息，收到回复即说明配置有效。要核对这次调用的扣费，可以查询 GET /v1/balance，见验证请求是否到达 NexusVAI。

排查问题

现象可能的原因解决方法
模型列表仍是 OpenAI 的默认模型列表没有刷新。手动输入 GET /v1/models 中的模型 ID。
404 model_not_found选择的模型 ID 不在 NexusVAI 的列表中。改用 GET /v1/models 中的 id。
421 relay_path_not_supported接口代理地址少了末尾的 /v1。填 https://cn.nexusvai.xyz/v1。
