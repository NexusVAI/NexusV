Cherry Studio 是一款桌面 AI 客户端，支持 OpenAI 兼容的自定义服务商。添加 NexusVAI 后，可以直接从 /v1/models 加载模型列表。

前提条件

  • 已安装 Cherry Studio。
  • 一个 NexusVAI API 密钥，可以在控制台创建。

添加服务商

  1. 打开 Cherry Studio，点击左下角的 设置。
  2. 在左侧选择 模型服务商。
  3. 选择 添加自定义服务商 或 OpenAI (Custom)，按下表填写。
  4. 点击 管理模型 或 刷新模型，从 /v1/models 加载模型列表。
  5. 在对话窗口顶部选择模型（例如 gpt-6-astra、claude-opus-5.5），开始聊天。
设置项值
服务商名称NexusVAI（可自定义）
API Keycancri_sk_...
API 地址https://cn.nexusvai.xyz/v1

验证配置

模型列表能加载出来，说明 API 地址可达；发送一条消息并收到回复，说明 Key 和模型 ID 也有效。要核对这次调用的扣费，可以查询 GET /v1/balance，见验证请求是否到达 NexusVAI。

排查问题

现象可能的原因解决方法
刷新后没有模型API 地址与上表不一致。填 https://cn.nexusvai.xyz/v1。如果报错 421 relay_path_not_supported，说明请求路径缺少 /v1。
能加载模型，但发送消息报 401Key 填错或已撤销。在控制台确认 Key 状态。
404 model_not_found手动添加的模型 ID 与列表不一致。从 /v1/models 加载的列表中选择模型。
