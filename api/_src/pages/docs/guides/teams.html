--- title: 团队 description: 团队让多人共用一份余额调用 API：管理员向团队划转余额，成员各自创建团队密钥，费用从团队余额扣除。 ---

团队适合小组、工作室、课程项目等多人协作的场景。成员不需要共享账号，也不需要互相传递密钥：每个人用自己的账户加入团队，各自创建团队密钥，调用费用统一从团队余额扣除。

创建与加入团队

  1. 登录控制台，进入团队页，填写团队名称（1–40 个字）即可创建。创建者是团队管理员。
  2. 管理员在「管理」中复制邀请链接发给成员，成员登录后打开链接即可加入。每个团队最多 50 人。
  3. 管理员可以随时重置邀请链接，旧链接立即失效。

每个账户同一时间只能加入一个团队；要换团队，先退出当前团队。解散团队后 24 小时内不能新建团队。

余额与计费

  • 团队余额独立于每位成员的个人 API 余额。团队密钥的调用只从团队余额扣费，不会动用成员的个人余额；个人密钥仍从个人余额扣费。
  • 管理员可以从自己的个人 API 余额向团队余额划转，每次 ¥1–¥10,000，精确到分。划转是单向的，划入团队后不能转回个人余额（解散团队时除外，见下文）。
  • 计费规则、模型价格与个人密钥完全相同。团队余额不足时返回 402 insufficient_balance。
  • 使用团队密钥调用 GET /v1/balance，返回的是团队余额；recent_usage 只包含这把密钥的调用记录。

团队密钥

团队密钥与个人密钥格式相同（以 cancri_sk_ 开头），Base URL、模型 ID 与调用方式完全一致，现有代码只需替换密钥。完整密钥只在创建时显示一次。

  • 每位成员在团队内最多持有 5 把有效的团队密钥，不占用个人密钥的名额。
  • 团队密钥归创建它的成员本人使用，不要转交他人。
  • 账户安全限制按密钥的持有人判定：某位成员的账户被限制时，其名下的团队密钥同样无法使用，其他成员不受影响。

速率限制与免费额度

  • 团队密钥使用团队自己的速率限制，不占用成员个人账户的限额。
  • 团队按累计划转到团队余额的金额定档，不继承成员的套餐或累计充值。档位门槛与个人账户相同，见速率限制。
  • 用团队密钥调用免费模型时，用量计入持有这把密钥的成员自己的免费额度。团队累计划转达到 ¥10 后，团队密钥不再受免费额度限制。

退出、移除与解散

  • 成员可以随时退出团队，管理员也可以移除成员。成员离开后，其创建的团队密钥立即吊销。
  • 成员在团队期间通过团队密钥产生的用量记录，仍作为团队账单保留。
  • 管理员不能直接退出；要离开团队，请解散团队。
  • 解散时，全部团队密钥吊销且不可恢复；团队余额扣除未结清的欠费后，退回管理员的个人 API 余额。
  • 还有进行中的请求时，解散会被拒绝：先吊销团队密钥，稍等几分钟再操作。
  • 团队欠费多于团队余额时，解散也会被拒绝：先划入不少于欠费的金额，再解散。

团队密钥产生的费用由团队余额承担。只把邀请链接发给信任的人；发现异常时，移除对应成员（其团队密钥随即失效）并重置邀请链接。

下一步

创建团队、邀请成员和划转余额。 团队密钥与个人密钥的用法相同。 预扣、结算与哪些情况会扣费。
