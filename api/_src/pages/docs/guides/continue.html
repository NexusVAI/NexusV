--- title: Continue description: 在 Continue 的 config.yaml 中把 OpenAI provider 指向 NexusVAI，用于 VS Code 和 JetBrains。 tab: coding ---

Continue 是支持 VS Code 和 JetBrains 的开源 AI 编程扩展。在 config.yaml 中添加一个使用 OpenAI provider 的模型，把 apiBase 指向 NexusVAI 即可。

前提条件

  • 已在 VS Code 或 JetBrains 中安装 Continue 扩展。
  • 一个 NexusVAI API 密钥，可以在控制台创建。
  • 要使用的模型 ID，例如 gpt-6-astra。

添加模型

打开 Continue 侧边栏的 Settings，编辑 config.yaml（也可以直接打开 ~/.continue/config.yaml），在 models 数组中追加一项：

models:
  - name: NexusVAI GPT-6 Astra
    provider: openai
    model: gpt-6-astra
    apiBase: https://cn.nexusvai.xyz/v1
    apiKey: cancri_sk_...
字段说明
name在模型下拉列表中显示的名称。
provideropenai。
modelNexusVAI 模型 ID，必须与 GET /v1/models 返回的一致。
apiBasehttps://cn.nexusvai.xyz/v1。
apiKey你的 API 密钥。

要添加更多模型，在 models 下按同样的格式再加几项，只改 name 和 model。

Continue 的 Agent 模式要求模型声明支持工具调用。如果自定义模型没有出现 Agent 选项，请按 Continue 官方文档为它补充 capabilities。

验证配置

保存后，在模型下拉列表中选择刚添加的模型，分别试一次对话和 Agent 的工具调用。然后查询这个 Key 最近的调用：

curl "https://cn.nexusvai.xyz/v1/balance?limit=5" \
  -H "Authorization: Bearer cancri_sk_..."

字段说明见验证请求是否到达 NexusVAI。

排查问题

现象可能的原因解决方法
模型下拉列表里没有新模型config.yaml 缩进或格式有误。检查 YAML 缩进，确认这一项位于 models 数组下。
没有 Agent 选项模型没有声明工具调用能力。按 Continue 文档补充 capabilities。
404 model_not_foundmodel 不在 GET /v1/models 的列表中。改成列表中的 id。
421 relay_path_not_supportedapiBase 少了末尾的 /v1。填 https://cn.nexusvai.xyz/v1。
