Cline 是 VS Code 的开源 AI 编程扩展。选择 OpenAI Compatible provider 并填入 NexusVAI 的地址和 API 密钥，就能在 Cline 的对话和 Agent 任务中使用 NexusVAI 的模型。

前提条件

  • 已在 VS Code 中安装 Cline 扩展。
  • 一个 NexusVAI API 密钥，可以在控制台创建。
  • 要使用的模型 ID，例如 gpt-6-astra 或 claude-opus-5.5。

配置 provider

  1. 在 VS Code 侧边栏打开 Cline，点击右上角的 设置（齿轮图标）。
  2. API Provider 选择 OpenAI Compatible。
  3. 按下表填写，然后保存。
设置项值
Base URLhttps://cn.nexusvai.xyz/v1
API Keycancri_sk_...
Model IDNexusVAI 模型 ID，例如 gpt-6-astra、claude-opus-5.5

验证配置

保存后点击 Verify，或给 Cline 发一条简短的消息，确认 Base URL、Key 和模型 ID 都有效。要确认请求确实到达 NexusVAI，查询这个 Key 最近的调用：

curl "https://cn.nexusvai.xyz/v1/balance?limit=5" \
  -H "Authorization: Bearer cancri_sk_..."

字段说明见验证请求是否到达 NexusVAI。

排查问题

现象可能的原因解决方法
404 model_not_foundModel ID 与 GET /v1/models 不一致。改成列表中的 id，注意大小写和连字符。
421 relay_path_not_supportedBase URL 少了末尾的 /v1。填 https://cn.nexusvai.xyz/v1。
401 invalid_api_keyKey 填错或已撤销。在控制台确认 Key 状态。
