怎么使用

把用户的第一条消息原文发给 cancri-alpha-0.8b，用返回的标题作为会话列表或历史记录的名称。不需要添加「请生成标题」的提示词。即使传入多轮对话，模型也只使用第一条用户文本。

输入示例标题示例
怎么用 Python 读取 Excel 文件？Python读取Excel方法

调用 API

先用 GET /v1/models 确认目录中有 cancri-alpha-0.8b。若没有，说明当前网关未开放这个模型；文档页面本身不代表服务已上架。

使用网关 API Key。Base URL 为 https://cn.nexusvai.xyz/v1，模型 ID 为 cancri-alpha-0.8b。以下示例从本机环境变量 CANCRI_API_KEY 读取密钥，不要把密钥放进浏览器端代码。

curl --fail-with-body https://cn.nexusvai.xyz/v1/chat/completions \
  -H "Authorization: Bearer $CANCRI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"cancri-alpha-0.8b","messages":[{"role":"user","content":"怎么用 Python 读取 Excel 文件？"}],"max_tokens":48}'
import os
from openai import OpenAI

client = OpenAI(base_url="https://cn.nexusvai.xyz/v1", api_key=os.environ["CANCRI_API_KEY"])
result = client.chat.completions.create(
    model="cancri-alpha-0.8b",
    messages=[{"role": "user", "content": "怎么用 Python 读取 Excel 文件？"}],
    max_tokens=48,
)
print(result.choices[0].message.content)

非流式请求从 choices[0].message.content 读取标题。使用 Responses 时可用 input 传入字符串；使用 Messages 时传入文本 messages 和 max_tokens。

输入、输出与限流

  • 首条用户文本须为 1–16,384 个字符。超过 1,024 个正文 token 时，保留前 768 个及后 256 个。
  • 默认最多生成 48 个 token。可以设置更小的输出上限，但标题可能被截断。stream: true 在生成完成后一次返回标题，不逐字输出。
  • 仅支持文本，不支持图片、文件、工具调用或结构化输出。收到 429 时按 Retry-After 等待后重试。
