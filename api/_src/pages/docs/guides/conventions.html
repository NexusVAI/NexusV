--- title: 使用约定 description: 接入前需要知道的几条约定：限额按账户计算、模型 ID 必须精确、Base URL 按协议填写，以及 API 的功能边界。 ---

这一页汇总接入时最容易误解的地方。照着它检查一遍配置，可以避开大部分 401、404 和 429。

限额按账户计算

速率限制按账户计算。同一账户的网页、桌面端、Bot 与 API 调用共用一组 RPM 与 TPM 限额，增加密钥不会提高限额。团队密钥使用团队自己的限额。详见速率限制。

使用 NexusVAI 模型 ID

  • model 必须是 NexusVAI 的模型 ID，取值见模型或 GET /v1/models。
  • ID 按字符精确匹配，大小写与连字符都要一致。不在列表里的 ID 返回 404 model_not_found。
  • 模型厂商的原始版本号（如 gpt-4-turbo、claude-3-5-sonnet-20241022）不可用。
  • 限时开放的模型过了访问期后不再可用，调用同样返回 404 model_not_found。

Base URL 按协议填写

  • 只使用概览中列出的地址。
  • OpenAI 兼容 SDK 的 Base URL 以 /v1 结尾：https://cn.nexusvai.xyz/v1。
  • Anthropic SDK 与 Claude Code 不带 /v1：https://cn.nexusvai.xyz。它们会自动拼接 /v1/messages 与 /v1/messages/count_tokens。

模型列表不代表可用性

  • GET /v1/models 不校验密钥，也不计费。它能返回结果，只说明服务在线，不说明你的密钥有效。验证密钥请调用 GET /v1/balance。
  • API 维护期间仍可读取模型列表，但 /v1/chat/completions、/v1/messages、/v1/responses 会返回 503 api_paused。
  • 模型列表只包含 ID 等基本信息，不包含价格，也不标注是否免费。价格与免费标记见模型与价格。

功能范围

API 只提供模型推理相关的能力：

能力状态
对话生成、流式输出、usage 统计支持，三种协议都可用
自定义函数工具与工具调用往返支持，部分模型可用
图片输入支持视觉的模型可用；只接受文本的模型返回 400 image_input_unsupported
推理强度参数部分模型生效，见各协议指南
实时语音使用单独的 WebSocket 端点，见实时语音
图像生成、视频生成不对 API 开放，返回 403 endpoint_disabled，仅网页版可用
Embeddings、音频转写、文件、向量库等端点不提供，返回 404
OpenAI 托管工具（网页搜索、文件检索、代码解释器、computer use）不在服务端执行
Responses 的服务端会话状态（previous_response_id、store）不支持，需要自己传完整历史

请求参数校验

网关会在转发前检查几个参数，不合规时返回 400 invalid_request_parameter，error.param 指出出错的字段：

  • service_tier 只接受省略、"auto" 或 "default"。合规的值也不会转发给模型。
  • GPT 系列模型的 reasoning_effort（Responses 为 reasoning.effort）只接受 none、low、medium、high、xhigh、max；reasoning.effort 额外接受 minimal。
  • max_tokens、max_output_tokens、temperature、top_p 必须是非负的有限数。

请求体不能超过 10 MB，否则返回 413 payload_too_large。

响应字段

  • 响应只保留各协议的标准字段。id 由 NexusVAI 生成，model 返回你请求的模型 ID。
  • usage 只包含输入、输出与总 token 数（Chat Completions 另有 completion_tokens_details.reasoning_tokens），不包含缓存命中的 token 数。缓存折扣体现在实际扣费里，可以用 GET /v1/balance 查看每次调用的 cost。
  • Chat Completions 中，模型公开的推理文本放在 message.reasoning_content（或 reasoning）字段。
