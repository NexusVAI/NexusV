NexusVAI API 用同一个 Base URL 和同一把 API 密钥提供所有模型，换模型只需修改请求中的 model。这一页介绍挑选模型时要看的几项信息：价格、上下文长度、能力标记和分组，以及如何用 API 列出可用的模型。

从旗舰模型开始

还不确定用哪个模型时，先从模型目录里的旗舰模型开始，用你自己的提示词和数据实际测一测，再根据效果、速度和费用调整。需要控制成本，可以先试「高性价比」分组里的模型，或者从免费模型开始。

比较价格

每个模型单独定价，价格以人民币计，完整列表见价格页，单个模型的价格见它的详情页。

计费方式怎么算
按 token输入与输出分别按每百万 token 计价。命中缓存的输入 token 按输入价格的 1 折计费。
按次每次成功的请求按固定价格扣费一次，与 token 数量无关。
免费不扣余额，调用计入免费额度，并受速率限制约束。

扣费以响应中的 usage 为准，返回 4xx 或 5xx 的失败请求不扣费。免费额度的规则见免费模型与免费额度。

上下文窗口与最大输出

模型卡片和详情页列出两个长度：上下文窗口是一次请求最多可以输入的 token 数，最大输出是一次响应最多生成的 token 数。处理长文档、长对话或带大量工具定义的请求时，选上下文窗口更大的模型。

看能力标记

模型目录为每个模型标出下面两项能力，详情页的「模态」与「特性」也按它们显示：

标记含义
图像输入可以在消息中附带图片。没有这个标记的模型，请只发送文本。
思考模式模型带有思考（推理）能力。

通过 API，所有模型都输出文本。图像与视频生成只对网页版开放，用 API 密钥调用 /v1/images/generations 或 /v1/videos/generations 会返回 403 endpoint_disabled。

分组：同一模型的多条线路

部分模型有多个分组，例如「标准」「Promo」或「按次」。每个分组都是一个独立的 Model ID，价格与配额可能不同。模型目录把它们合并成一张卡片，点击卡片上的分组即可查看对应的 Model ID 和价格；价格页的「全部分组」会列出每一个分组。

分组区分的是 Model ID，不是 API 密钥。同一把密钥可以调用所有分组，只要把对应的 Model ID 填进请求。

用 API 列出模型

调用 GET /v1/models 获取当前可用的 Model ID，返回 OpenAI 兼容的列表：

import os
from openai import OpenAI

client = OpenAI(base_url="https://cn.nexusvai.xyz/v1", api_key=os.environ.get("CANCRI_API_KEY"))

for model in client.models.list():
    print(model.id)
import OpenAI from "openai";

const client = new OpenAI({ baseURL: "https://cn.nexusvai.xyz/v1", apiKey: process.env.CANCRI_API_KEY });

for await (const model of client.models.list()) {
  console.log(model.id);
}
curl https://cn.nexusvai.xyz/v1/models \
  -H "Authorization: Bearer $CANCRI_API_KEY"

每个条目包含 id、object、created、owned_by，部分条目还带 max_output_tokens；Anthropic 客户端（例如 Claude Code）收到的是 Anthropic 格式的列表。价格与能力标记不在这个接口里，请以模型目录和价格页为准。

请求里的 Model ID 必须与列表返回值完全一致，包括大小写与连字符。有的客户端会自动改写模型名，这时请在客户端的模型设置里手动填写。
