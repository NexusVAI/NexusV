什么是嵌入？

嵌入是用浮点数向量表示文本、图像等数据的方法。同一个模型生成的向量可以比较距离，用来近似衡量输入之间的相关性。向量本身不是文本答案。

如何获取嵌入

选择适合数据语言与领域的嵌入模型。在应用侧切分长文档，用同一种模型和配置为文档及查询生成向量。把文档片段与向量一起存入你的向量索引；模型或维度发生变化时，重新生成索引，不要混用不同向量空间的结果。

选择嵌入模型

比较模型时，记录检索召回率、维度、延迟、存储成本和数据授权。维度越大，索引通常越占空间；维度小不一定效果差，应在你的代表性查询上验证。

降低嵌入维度

只有模型或工具明确支持时，才调整输出维度。变更前分别检查相关性召回、查询延迟、存储占用；查询向量与索引向量必须使用相同维度。

使用场景

  • 语义搜索：比较查询向量与文档片段向量，再按相似度排序。
  • 检索增强生成：在应用侧找出最相关的片段，将原文传给 Responses API，再用引用格式标明来源。
  • 聚类、异常检测和推荐：比较距离前先验证同一向量空间是否能反映任务所关心的相似性。

text-embedding-3-small 和 text-embedding-3-large是我们最新且性能最强的嵌入模型，现已上线。它们成本更低、多语言性能更高，并新增了用于控制整体维度的参数。

什么是嵌入？

OpenAI 的文本嵌入用于衡量文本字符串之间的相关性。嵌入常用于：

  • 搜索（按与查询字符串的相关性对结果排序）
  • 聚类（按相似性对文本字符串分组）
  • 推荐（推荐文本相关的项目）
  • 异常检测（找出相关性很低的离群值）
  • 多样性度量（分析相似度分布）
  • 分类（按最相似的标签对文本字符串进行分类）

嵌入是一个浮点数向量（列表）。两个向量之间的距离衡量它们的相关性。距离较小表示高度相关，距离较大表示相关性低。

嵌入的费用请参见价格页。请求按 token 数计费，计算的是输入的 token 数。

func embedding(ctx context.Context, client *openai.Client, text string) ([]float64, error) {

		Model: openai.EmbeddingModelTextEmbedding3Small,

	if err != nil {
		return nil, err
	}
	return response.Data[0].Embedding, nil
}

降低嵌入维度

与低维嵌入相比，使用高维嵌入（例如将其存入向量库以供检索）通常成本更高，也需要更多算力、内存和存储空间。

这两个新嵌入模型都采用了一种训练方法，让开发者可以在嵌入效果与使用成本之间取舍。传入 dimensions API 参数即可缩短嵌入向量（从序列末尾去掉部分数值），同时保留它表示概念的能力。例如，在 MTEB 基准测试中，text-embedding-3-large 缩短到 256 维后，表现仍优于未经缩短的 1536 维 text-embedding-ada-002 嵌入。维度变化对性能的影响详见嵌入模型 v3 发布博文。

通常建议在生成嵌入时，用 dimensions 参数指定维度。如果需要在生成后手动调整，请像下面这样对调整后的嵌入向量做归一化处理。

def normalize_l2(x):
    x = np.array(x)
    if x.ndim == 1:
        norm = np.linalg.norm(x)
        if norm == 0:
            return x
        return x / norm
    else:
        norm = np.linalg.norm(x, 2, axis=1, keepdims=True)
        return np.where(norm == 0, x, x / norm)

func cosineSimilarity(a, b []float64) float64 {

		left += a[i] * a[i]

func cosineSimilarity(a, b []float64) float64 {
	var dot, left, right float64
	for i := range a {
		dot += a[i] * b[i]
		left += a[i] * a[i]
		right += b[i] * b[i]
	}
	return dot / math.Sqrt(left*right)
}

type match struct {
	Index      int
	Similarity float64

func nearest(query []float64, vectors [][]float64) []match {
	matches := make([]match, len(vectors))
	for i, vector := range vectors {
		matches[i] = match{Index: i, Similarity: cosineSimilarity(query, vector)}
	}
	sort.SliceStable(matches, func(i, j int) bool { return matches[i].Similarity > matches[j].Similarity })
	return matches
}

应该使用哪种距离函数？

推荐使用余弦相似度。通常，距离函数的选择对结果影响不大。

OpenAI 的嵌入向量都已归一化为长度 1，因此：

  • 只需做一次点积就能计算余弦相似度，速度略快。
  • 使用余弦相似度或欧氏距离排序，结果相同。

可以在网上分享自己的嵌入吗？

可以。客户拥有提交给 OpenAI 模型的输入，以及从模型获得的输出，嵌入也不例外。你有责任确保提交给 API 的内容不违反任何适用法律或 OpenAI 的《使用条款》。

V3 嵌入模型了解近期事件吗？

不了解。text-embedding-3-large 和 text-embedding-3-small 不掌握 2021 年 9 月之后发生的事件。与文本生成模型相比，这一限制对嵌入模型的影响通常较小，但在某些特殊情况下仍可能降低效果。
