--- title: OpenCode description: 在 opencode.json 中添加一个自定义 provider，让 OpenCode 通过 AI SDK 调用 NexusVAI 的模型。 tab: coding ---

OpenCode 是一个开源的终端编程智能体，用 AI SDK 的 provider 机制接入模型。你只需要在配置文件里添加一个指向 NexusVAI 的 provider，并列出要用的模型。

前提条件

  • 已安装 OpenCode。
  • 一个 NexusVAI API 密钥，可以在控制台创建。
  • 要使用的模型 ID，取自 GET /v1/models。

添加 provider

编辑用户级配置 ~/.config/opencode/opencode.json，或项目根目录的 opencode.json：

{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "cancri": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "NexusVAI",
      "options": {
        "baseURL": "https://cn.nexusvai.xyz/v1",
        "apiKey": "cancri_sk_..."
      },
      "models": {
        "gpt-6-astra": {},
        "claude-opus-5.5": {},
        "deepseek-v4-flash": {},
        "gemini-3.8-flash-high": {}
      }
    }
  }
}
字段说明
provider.cancriprovider id，可以自定义。
npm使用的 AI SDK 包，决定请求哪个端点，见下一节。
name在 OpenCode 中显示的名称。
options.baseURLhttps://cn.nexusvai.xyz/v1。
options.apiKey你的 API 密钥。
models要在 OpenCode 中使用的模型。键是 NexusVAI 的模型 ID。

项目根目录的 opencode.json 容易被一起提交到代码仓库。Key 写在里面时，请把文件加入 .gitignore，或者把 provider 配置放在用户级配置中。

选择 provider 包

npm请求的端点适合
@ai-sdk/openai-compatible（默认）/v1/chat/completions大多数模型。
@ai-sdk/openai/v1/responses想和 Codex 一样走 Responses 协议时，例如 gpt-6-astra。具体写法以 OpenCode 官方文档为准。

验证配置

在 OpenCode 中切换到 cancri provider 下的模型，发送一条简短的消息。然后查询这个 Key 最近的调用：

curl "https://cn.nexusvai.xyz/v1/balance?limit=5" \
  -H "Authorization: Bearer cancri_sk_..."

recent_usage.data 里应该出现刚才的请求。字段说明见验证请求是否到达 NexusVAI。

排查问题

现象可能的原因解决方法
模型列表里看不到 NexusVAI 的模型配置文件路径不对，或 JSON 格式有误。确认文件位置，并检查 JSON 是否合法。
404 model_not_foundmodels 里的键不在 GET /v1/models 的列表中。改成列表中的 id，注意大小写和连字符。
401 invalid_api_keyoptions.apiKey 填错或 Key 已撤销。在控制台确认 Key 状态。
421 relay_path_not_supportedbaseURL 少了末尾的 /v1。填 https://cn.nexusvai.xyz/v1。
