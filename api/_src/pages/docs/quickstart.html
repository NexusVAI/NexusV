--- title: 快速开始 description: 创建 API 密钥，安装 SDK，几分钟内发出第一个请求。 ---

这篇指南带你完成第一次调用：创建密钥、安装官方 SDK、发送请求，再把它改成流式输出。示例使用 OpenAI SDK 和 Chat Completions 协议；如果你在用 Anthropic SDK，流程相同，代码见 Messages 指南。

创建 API 密钥

  1. 登录 NexusVAI。注册后即可创建密钥，无需审核。
  2. 打开控制台的 API 密钥页，创建一把新密钥。
  3. 复制并保存完整密钥。它以 cancri_sk_ 开头，只在创建时显示一次。

把密钥存进环境变量，不要写在代码里：

export CANCRI_API_KEY="cancri_sk_..."
$env:CANCRI_API_KEY = "cancri_sk_..."

安装 SDK

NexusVAI 兼容 OpenAI 官方 SDK，不需要额外的客户端库。使用 cURL 时可以跳过这一步。

pip install openai
npm install openai

发起第一次请求

把 base_url 指向 https://cn.nexusvai.xyz/v1，然后照常调用 SDK：

import os
from openai import OpenAI

client = OpenAI(
    base_url="https://cn.nexusvai.xyz/v1",
    api_key=os.environ["CANCRI_API_KEY"],
)

response = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[
        {"role": "system", "content": "你是一个简洁的助手。"},
        {"role": "user", "content": "用一句话解释什么是行级安全。"},
    ],
)
print(response.choices[0].message.content)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://cn.nexusvai.xyz/v1",
  apiKey: process.env.CANCRI_API_KEY,
});

const response = await client.chat.completions.create({
  model: "deepseek-v4-flash",
  messages: [
    { role: "system", content: "你是一个简洁的助手。" },
    { role: "user", content: "用一句话解释什么是行级安全。" },
  ],
});
console.log(response.choices[0].message.content);
curl https://cn.nexusvai.xyz/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $CANCRI_API_KEY" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [
      {"role": "system", "content": "你是一个简洁的助手。"},
      {"role": "user", "content": "用一句话解释什么是行级安全。"}
    ]
  }'

响应是标准的 Chat Completions 对象。模型的回答在 choices[0].message.content，本次用量在 usage：

{
  "id": "chatcmpl-...",
  "object": "chat.completion",
  "created": 1762480000,
  "model": "deepseek-v4-flash",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "行级安全是一种按行控制谁能读写数据的数据库策略。"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": { "prompt_tokens": 28, "completion_tokens": 19, "total_tokens": 47 }
}

model 换成任意可用的模型 ID 即可切换模型。可用的 ID 见模型，也可以请求 GET /v1/models。

流式输出

设置 stream: true，模型会边生成边返回增量文本，适合聊天界面和较长的回答：

stream = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "写一首关于秋天的四行诗。"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
const stream = await client.chat.completions.create({
  model: "deepseek-v4-flash",
  messages: [{ role: "user", content: "写一首关于秋天的四行诗。" }],
  stream: true,
});
for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}
curl https://cn.nexusvai.xyz/v1/chat/completions \
  -N \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $CANCRI_API_KEY" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [{"role": "user", "content": "写一首关于秋天的四行诗。"}],
    "stream": true
  }'

流式响应的最后一个 chunk 携带本次的 usage，它的 choices 是空数组。读取 choices[0] 之前先判断数组非空，否则 Python 会抛出 IndexError。

检查密钥与余额

GET /v1/models 不校验密钥，能返回结果不代表密钥有效。要确认密钥可用，请调用 GET /v1/balance：它校验密钥并返回账户余额，不计费。

curl https://cn.nexusvai.xyz/v1/balance \
  -H "Authorization: Bearer $CANCRI_API_KEY"

返回 401 invalid_api_key 说明密钥无效或已撤销。其他错误见错误码。
