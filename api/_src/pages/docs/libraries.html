--- title: SDK 与兼容性 description: 用 OpenAI 或 Anthropic 的官方 SDK、常见框架和工具调用 NexusVAI，只需修改 Base URL 与密钥。 ---

NexusVAI 没有自己的 SDK。接口兼容 OpenAI 协议（Chat Completions、Responses）和 Anthropic 协议（Messages），你可以直接使用这两家的官方 SDK，以及基于它们构建的框架和工具。切换时只需修改两个参数：Base URL 和 API 密钥。

OpenAI SDK

安装官方 openai 包，把 Base URL 设为 https://cn.nexusvai.xyz/v1：

# pip install openai
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://cn.nexusvai.xyz/v1",
    api_key=os.environ["CANCRI_API_KEY"],
)
// npm install openai
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://cn.nexusvai.xyz/v1",
  apiKey: process.env.CANCRI_API_KEY,
});

官方 SDK 也会读取环境变量。只设置环境变量、不改代码也可以：

export OPENAI_BASE_URL="https://cn.nexusvai.xyz/v1"
export OPENAI_API_KEY="cancri_sk_..."

Chat Completions 用 client.chat.completions.create，Responses 用 client.responses.create。用法见 Chat Completions 与 Responses 指南。

Anthropic SDK

安装官方 Anthropic SDK（Python 包名 anthropic，Node.js 包名 @anthropic-ai/sdk），把 Base URL 设为 https://cn.nexusvai.xyz。SDK 会自动拼接 /v1/messages，不要自己再加 /v1。

# pip install anthropic
import os
from anthropic import Anthropic

client = Anthropic(
    base_url="https://cn.nexusvai.xyz",
    api_key=os.environ["CANCRI_API_KEY"],
)
// npm install @anthropic-ai/sdk
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://cn.nexusvai.xyz",
  apiKey: process.env.CANCRI_API_KEY,
});

使用环境变量时，密钥可以放在 ANTHROPIC_API_KEY（以 x-api-key 请求头发送，推荐）或 ANTHROPIC_AUTH_TOKEN（以 Authorization: Bearer 发送）中，二选一：

export ANTHROPIC_BASE_URL="https://cn.nexusvai.xyz"
export ANTHROPIC_API_KEY="cancri_sk_..."

用法见 Messages 指南。

框架与聚合工具

基于上述协议的框架也可以直接使用：

框架或工具使用的包或类协议
Vercel AI SDK@ai-sdk/openai、@ai-sdk/openai-compatible、@ai-sdk/anthropicOpenAI / Anthropic
LangChainChatOpenAI、ChatAnthropicOpenAI / Anthropic
LiteLLM、OneAPI、Cherry Studio 等聚合工具选择 OpenAI 兼容的渠道或提供商OpenAI
 
# pip install langchain-openai
import os
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="deepseek-v4-flash",
    base_url="https://cn.nexusvai.xyz/v1",
    api_key=os.environ["CANCRI_API_KEY"],
)
print(llm.invoke("用一句话介绍你自己。").content)
// npm install ai @ai-sdk/openai-compatible
import { createOpenAICompatible } from "@ai-sdk/openai-compatible";
import { generateText } from "ai";

const nexusvai = createOpenAICompatible({
  name: "nexusvai",
  baseURL: "https://cn.nexusvai.xyz/v1",
  apiKey: process.env.CANCRI_API_KEY,
});

const { text } = await generateText({
  model: nexusvai("deepseek-v4-flash"),
  prompt: "用一句话介绍你自己。",
});
console.log(text);

编程工具与客户端

Codex CLI、Claude Code、OpenCode、OpenClaw、Aider 等命令行智能体，以及 Cursor、Cline、Continue、Cherry Studio 等编辑器和客户端，都可以通过自定义 Base URL 接入。各工具的配置步骤见编程工具。

兼容范围

  • 同一把密钥可以同时用于两类 SDK。速率限制按账户计算，不区分协议与密钥。
  • 请求与响应格式与原协议一致。支持流式输出、usage 统计和自定义函数工具（部分模型支持工具调用）。
  • 只有模型推理相关的端点。OpenAI 的文件、向量库、托管工具（网页搜索、文件检索、代码解释器、computer use）和 Responses 的服务端会话状态都不可用。

完整的功能边界见使用约定。
