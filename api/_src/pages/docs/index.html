--- title: NexusVAI API description: 用一把 API 密钥，通过 OpenAI 与 Anthropic 协议调用 GPT、Claude、Gemini、DeepSeek 等模型。 ---

NexusVAI API 把多家前沿模型放在同一个端点后面。你用同一把 cancri_sk_ 密钥、同一份余额调用所有模型，接口兼容 OpenAI Chat Completions、OpenAI Responses 与 Anthropic Messages 三种协议。现有代码通常只需改 Base URL、密钥和模型 ID 就能运行。

发起第一次请求

先在控制台创建一把 API 密钥，并保存到环境变量 CANCRI_API_KEY。然后用 OpenAI 官方 SDK 发送请求：

import os
from openai import OpenAI

client = OpenAI(
    base_url="https://cn.nexusvai.xyz/v1",
    api_key=os.environ["CANCRI_API_KEY"],
)

response = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "用一句话介绍你自己。"}],
)
print(response.choices[0].message.content)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://cn.nexusvai.xyz/v1",
  apiKey: process.env.CANCRI_API_KEY,
});

const response = await client.chat.completions.create({
  model: "deepseek-v4-flash",
  messages: [{ role: "user", content: "用一句话介绍你自己。" }],
});
console.log(response.choices[0].message.content);
curl https://cn.nexusvai.xyz/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $CANCRI_API_KEY" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [{"role": "user", "content": "用一句话介绍你自己。"}]
  }'

完整步骤（含流式输出）见快速开始。

Base URL

按客户端使用的协议填写 Base URL。OpenAI 兼容的 SDK 和工具以 /v1 结尾；Anthropic SDK 会自己拼接 /v1/messages，所以不带 /v1。

协议Base URL常见客户端
OpenAI（Chat Completions、Responses）https://cn.nexusvai.xyz/v1OpenAI SDK、Codex CLI、Cursor、Cline、Continue、Cherry Studio
Anthropic（Messages）https://cn.nexusvai.xyzAnthropic SDK、Claude Code、OpenClaw

你也可以使用备用地址 https://chat.nexusvai.xyz/functions/v1/api-gateway（OpenAI 协议在末尾加 /v1）。两个地址背后是同一套服务，密钥、模型 ID、请求格式与计费完全相同。

端点

端点用途
POST /v1/chat/completionsOpenAI Chat Completions。支持的工具最多，适合大多数场景。见指南。
POST /v1/responsesOpenAI Responses。Codex CLI 等默认使用这个协议。见指南。
POST /v1/messagesAnthropic Messages。Claude Code、Anthropic SDK 使用这个协议，model 不限于 Claude。见指南。
POST /v1/messages/count_tokens估算一次 Messages 请求的输入 token 数。Claude Code 会自动调用。
GET /v1/models列出可用模型。不校验密钥。见 API 参考。
GET /v1/balance查询余额、当前密钥的限额与最近的调用记录。见查询余额与用量。

前三个端点按用量计费，后三个端点免费。

实时语音对话使用单独的 WebSocket 端点，见实时语音。API 不提供图像生成、视频生成、Embeddings、音频转写、文件与向量库等端点；哪些能用、哪些不能用，见使用约定。

计费与限额

API 按用量从余额扣费，每个模型单独定价，价格见价格。标为免费的模型不扣余额，但计入每 24 小时 1 亿 token 的免费额度。

速率限制按账户计算，只有每分钟请求数（RPM）和每分钟 token 数（TPM）两项，档位随累计充值提升。详见计费与余额和速率限制。
