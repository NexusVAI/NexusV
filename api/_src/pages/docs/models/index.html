选择模型

不确定从哪里开始，就先用 GPT-6.1 Sol；更看重某个场景时，再浏览下方的旗舰模型与全部模型。需要控制成本，可以在价格页比较各模型的单价，或从免费模型开始。

所有模型都通过同一个 Base URL 调用，兼容 OpenAI 与 Anthropic 协议，换模型只需修改请求中的 model 参数。命中缓存的输入 token 默认按输入价格的 1 折计费（Claude Opus 5.5 含 Thinking 为 3 折），为什么检测工具显示无缓存？

Base URL https://cn.nexusvai.xyz/v1
