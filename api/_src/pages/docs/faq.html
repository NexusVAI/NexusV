--- title: 常见问题 description: 接入 NexusVAI API 时最常遇到的问题与答案。 ---

没有找到答案？先看错误码和使用约定，或者联系我们。

接入

三个端点我该用哪个？

  • 通用对话用 /v1/chat/completions，支持的工具最多。
  • Codex CLI 等默认使用 Responses 协议的客户端，用 /v1/responses。
  • Claude Code、Anthropic SDK、OpenClaw 用 /v1/messages。

三个端点使用同一份模型目录、同一把密钥和同一套计费。Claude Code 还会自动调用 /v1/messages/count_tokens 估算上下文长度，这个端点不计费，无需配置。

能通过 API 生成图片或视频吗？

不能。/v1/images/generations 与 /v1/videos/generations 只对网页版开放，用 API 密钥调用返回 403 endpoint_disabled。网页版的图像生成按次计费，价格见价格。

命令行工具的模型列表里找不到我要的模型

命令行客户端（尤其是 Claude Code）通常在启动时读取一次 GET /v1/models，填写的模型 ID 必须在这个列表里。你可以直接请求 GET /v1/models，或在模型页查询可用 ID。模型厂商的原始版本号（如 claude-3-5-sonnet-20241022）不可用。

Claude Code 会按自己的规则过滤选择器里显示的模型。非 Claude 命名的模型能否使用，取决于客户端是否允许手动填写模型 ID。

支持工具调用吗？

支持自定义函数工具与工具调用往返，具体是否可用取决于模型。OpenAI 的托管工具（网页搜索、文件检索、代码解释器、computer use）不会在服务端执行。

能在浏览器里直接调用 API 吗？

不要这样做。前端代码里的密钥对所有访问者可见，等同于公开；而且 API 的跨域访问只对 NexusVAI 自己的网站开放，第三方网页的浏览器请求会被拦截。请从你自己的服务端发起请求，把密钥保存在服务端环境变量里。

有地区或 IP 限制吗？

不按国家或地区限制访问。检测到异常 IP 或滥用行为时，可能临时限制访问。同一 IP 在短时间内多次使用不存在的密钥，会收到 429 auth_rate_limited。

密钥丢了怎么办？

完整密钥只在创建时显示一次，之后无法找回。在控制台的 API 密钥页撤销旧密钥，再创建一把新的。

计费与额度

怎么计费？

按实际用量从余额扣费，每个模型的价格见价格：多数模型按输入与输出 token 计费，命中缓存的输入默认按输入价格的 1 折计算（Claude Opus 5.5 含 Thinking 为 3 折），部分能力按次计费。请求开始前按预估金额预扣，结束后按实际 usage 结算，多退少补。详见计费与余额。

第三方工具显示「无缓存」，缓存真的生效了吗？

缓存折扣已经计入每次调用的扣费，但出于安全考虑，响应的 usage 不返回缓存命中的 token 数，按其他服务的字段格式检测的工具会显示「无缓存」。你可以用 GET /v1/balance 返回的 cost 或控制台用量页核对实际扣费。另外，缓存只在请求前缀完全一致、长度达到模型的最低要求时命中，且只保留几分钟。见提示缓存。

免费账户和已充值账户有什么区别？

没有充值也没有套餐的账户是 Tier 0：60 RPM、2,000,000 TPM，免费模型受每 24 小时 1 亿 token 的免费额度限制。累计充值达到 ¥10 或开通套餐后，档位提升，免费模型也不再受免费额度限制。见速率限制与免费模型与免费额度。

怎么提升速率限制档位？

累计充值达到门槛或开通套餐后，档位自动提升，通常 1 分钟内生效，无需重新创建密钥。档位门槛见速率限制。充值方式：在控制台的账单页购买充值卡并兑换卡密，兑换后立即到账。

怎么查看用量？

调用 GET /v1/balance 可以查看余额、当前密钥的限额和最近的调用记录；控制台的用量页可以查看最近 30 天的调用与消费。见查询余额与用量。

故障排查

返回 503 api_paused 是什么意思？

API 正在维护。维护期间 GET /v1/models 仍可读取模型列表，推理接口返回 503 api_paused，响应带 Retry-After。更换密钥或客户端无法解除，请等待维护结束。

返回 404 model_not_found

模型 ID 必须与 GET /v1/models 的返回值完全一致，包括大小写与连字符。部分客户端会自动改写模型名，这时请在模型设置中手动填写 NexusVAI 模型 ID（如 gpt-6-astra、claude-sonnet-5.5）。

模型返回 upstream_rate_limit 或 upstream_error

这类错误表示所选模型暂时繁忙或不可用，与你的密钥、余额和档位无关。按 Retry-After 退避后重试，或换用其他模型。见模型暂时不可用。

有 SLA 吗？

NexusVAI 不提供 SLA。在生产环境中，建议自己实现重试与故障转移，例如在模型不可用时切换到备用模型。见生产最佳实践。
