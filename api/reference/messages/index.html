文本生成

创建消息

POST
/v1/messages

根据对话生成下一条助手消息。请求与响应遵循 Anthropic Messages 协议，Claude Code、官方 Anthropic SDK 等客户端把 Base URL 设为 https://cn.nexusvai.xyz（不带 /v1）即可使用。model 不限于 Claude 系列，GET /v1/models 中的模型都可以调用。用法见 Messages 指南。

网关会把请求转换成 Chat Completions 发给模型，再把结果转换回 Anthropic 格式，所以只转发下面列出的字段。请求中的内容块只支持 text、image、tool_use 与 tool_result，其他类型返回 400 unsupported_anthropic_content，不会被悄悄丢弃。

请求头
x-api-key: string必填

你的 API 密钥 cancri_sk_…。也可以改用 Authorization: Bearer cancri_sk_…（Anthropic SDK 的 authToken 或 Claude Code 的 ANTHROPIC_AUTH_TOKEN）。

anthropic-version: string可选

可以照常发送（例如 2023-06-01），网关不校验它的取值。anthropic-beta 同样不会改变网关行为。

请求体
model: string必填

要使用的模型 ID，取值见 GET /v1/models。模型厂商的原始版本号（如 claude-3-5-sonnet-20241022）不可用。不存在时返回 404（not_found_error）。

max_tokens: integer必填

本次最多生成的 token 数，必须是非负数。Anthropic 协议要求必填，官方 SDK 也会校验；网关在缺省时按模型目录的输出上限补上，不会因此拒绝请求。这个值也用于预占本次请求的 TPM。

messages: array of object必填

对话历史，user 与 assistant 交替出现。
role: "user" or "assistant"必填
content: string or array必填

字符串，或内容块数组。内容块上的 cache_control 不生效。
支持以下内容块：
text: object

{"type": "text", "text": "…"}。

image: object

仅用户消息。source 为 {"type": "base64", "media_type": "image/png", "data": "…"} 或 {"type": "url", "url": "…"}，需要模型支持视觉输入。

tool_use: object

仅助手消息。模型此前发起的工具调用：id、name、input，按上一轮响应原样回传。

tool_result: object

仅用户消息。工具的执行结果：tool_use_id 与 content（字符串或 text 块数组；不支持图片）。

PDF 等 document 块、thinking / redacted_thinking 块以及其他类型会返回 400 unsupported_anthropic_content。
system: string or array可选

系统提示：字符串，或 text 块组成的数组（其他块类型返回 400）。

stream: boolean可选默认 false

设为 true 时返回 Anthropic 流式事件，见流式事件。Claude Code 默认使用流式输出。

temperature: number可选

采样温度，必须是非负数。

top_p: number可选

核采样阈值，必须是非负数。

stop_sequences: array of string可选

停止序列。命中时 stop_reason 为 end_turn，stop_sequence 始终为 null。

tools: array of object可选

自定义工具，调用结果通过 tool_use / tool_result 往返。不支持 web_search、代码执行等 Anthropic 服务端工具。
name: string必填

工具名。

description: string可选

工具用途。

input_schema: object可选

描述工具输入的 JSON Schema。省略时按空对象处理。

tool_choice: object可选

{"type": "auto"}、{"type": "any"}（必须调用某个工具）、{"type": "none"}，或 {"type": "tool", "name": "…"}。disable_parallel_tool_use 会被忽略。

thinking: object可选

{"type": "enabled", "budget_tokens": N} 会按预算换算成推理强度：低于 4,096 为 low，低于 16,384 为 medium，低于 32,768 为 high，更高为 max。只对已验证支持推理强度的模型生效。思考内容以普通 text 块返回，不返回 thinking 块与签名。

output_config: object可选

output_config.effort（low、medium、high、xhigh、max）优先于 thinking，同样只对已验证的模型生效。

其他字段会被忽略，包括 metadata、top_k、container、mcp_servers。service_tier 只接受 auto 或 default（也可以省略），standard_only 等其他值返回 400 invalid_request_parameter。

返回
id: string

格式为 msg_ 加 24 位十六进制字符，由 NexusVAI 生成。

type: "message"
role: "assistant"
model: string

公开模型 ID。

content: array of object

text 块（模型的思考内容与拒绝说明也以 text 块返回，排在回答之前）与 tool_use 块（id 以 toolu_cx 开头，name，input）。工具参数不是合法 JSON 时，input 为 {"_raw": "…"}。

stop_reason: string

end_turn、max_tokens 或 tool_use。

stop_sequence: null

始终为 null。

usage: object

input_tokens 与 output_tokens。不返回 cache_read_input_tokens 等缓存字段；缓存折扣已计入扣费。

流式事件

事件按以下顺序出现，每个事件由 event: 与 data: 两行组成。网关不发送 ping 事件。

message_start

消息骨架，content 为空。其中的 usage 为 0，实际用量在 message_delta 中给出。

content_block_start

一个 text 或 tool_use 块开始，带 index。

content_block_delta

增量内容：text_delta（文本）或 input_json_delta（工具输入的 JSON 片段，按顺序拼接）。

content_block_stop

一个块结束。

message_delta

给出 stop_reason 与 usage（input_tokens、output_tokens）。

message_stop

消息正常结束。

error

流在中途失败：先发送 stop_reason 为 null 的 message_delta，再发送 error，不发送 message_stop。error.code 为模型给出的原因，或 upstream_interrupted、upstream_truncated、upstream_empty_response。

错误

模型、计费、限流与上游错误使用 Anthropic 格式 {"type": "error", "error": {"type", "message", "code"}}。认证、请求体校验与密钥限制等前置检查返回的错误（如 401 invalid_api_key、413 payload_too_large、403 model_not_in_whitelist）使用 OpenAI 格式 {"error": {"message", "type", "code"}}。

unsupported_anthropic_content: 400

请求包含不支持的内容块，message 指出具体位置，例如 messages[0].content[1]。

not_found_error: 404

模型不存在（这是 error.type，不带 code）。

insufficient_balance: 402

余额不足以支付本次请求的预估费用，不要自动重试。

rate_limit_exceeded: 429

超出 RPM 或 TPM，按 Retry-After 等待后重试。响应带 anthropic-ratelimit-* 响应头。

upstream_error: 4xx / 5xx

模型暂时不可用或超时（error.type 为 api_error）。upstream_rate_limit（429）表示模型繁忙，与你的账户限额无关。

完整列表见错误。

14import os
from anthropic import Anthropic

client = Anthropic(base_url="https://cn.nexusvai.xyz", api_key=os.environ["CANCRI_API_KEY"])

stream = client.messages.create(
    model="claude-sonnet-5.5",
    max_tokens=256,
    messages=[{"role": "user", "content": "你好"}],
    stream=True,
)
for event in stream:
    if event.type == "content_block_delta" and event.delta.type == "text_delta":
        print(event.delta.text, end="", flush=True)
