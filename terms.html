2. 服务说明

NexusV 是一个聚合主流大语言模型与多模态 AI 模型的对话与生成平台。当前接入的上游模型供应方包括但不限于：阿里云百炼（DashScope）、魔搭社区（ModelScope）、OpenAI、Anthropic、DeepSeek 等（生产环境经由统一网关按线路路由与协议转换后转发）。

本服务的核心功能包括：

  • 对话推理：通过统一界面与各上游模型对话；
  • 多模型切换：在同一会话中横向比较不同模型的输出；
  • 图像生成：调用支持图像生成的模型创建图像；
  • Cancri Code IDE：桌面端编程助手客户端，与网页端共享同一账户与套餐额度；
  • 开放 API：为开发者提供与 OpenAI 兼容的 API 接口（详见 API 文档）。

本服务以"现状"提供，我们尽力保证服务的稳定与可用，但不承诺服务永远可用、永远准确、永远无故障。上游模型供应方的可用性、定价与配额变化可能影响本服务。

项目性质：NexusV 为独立维护者运营的非商业项目，代码开源于 github.com/NexusVAI。本服务无正式公司实体、无 SLA 承诺、无 7×24 客服。起源于独立开发者对 AI 工具的探索，以个人名义为社区充当上游 API 与终端用户之间的聚合层。

7. 付费、订阅与退款

7.1 免费与付费机制

本服务对所有注册用户开放免费档。付费形态分为两条相互独立的轨道：面向网页对话与 Cancri Code IDE 的月度套餐，以及面向开发者开放 API 的按量充值。价格、规格与额度以 套餐页 当时所列为准。

  • 个人套餐（Chat 网页 + Cancri Code IDE 双端通用）：按月计费、随时取消、不自动续费，当前分三档：
    • Go（¥9.9 / 月）：每月约 ¥15 平台额度；
    • Plus（¥19 / 月）：每月约 ¥45 平台额度；
    • Pro（¥99 / 月）：每月约 ¥300 平台额度。
    套餐额度按平台统一模型定价计量（内部以人民币计价），全模型开放、按实际调用从额度扣减；额度当月有效、不结转至次月；套餐额度仅用于 Chat / IDE，与 API 额度相互独立。
  • 开放 API 按量充值（cancri_sk_ 密钥）：面向开发者的公开 API 采用预充值 ¥ 钱包、按用量实时扣费的模式（按各模型的统一定价结算），与套餐额度完全隔离、互不挪用。详见 API 文档。

同档或更高档套餐可续费 / 升级；套餐到期后自动降级回免费档。限时活动期间，API 钱包余额可等值换购套餐（以站内公示为准）。配额、模型范围与速率上限的具体数值以 套餐页、模型广场 与 API 文档 当时所列为准。

7.2 付款与激活流程

付费采用微信 / 支付宝个人收款 + 站主人工审核的模式，不接入第三方支付平台。完整流程：

  1. 扫码付款：微信或支付宝扫码付费，请在付款备注里填写您的邮箱 + QQ（以便对单）；
  2. 提交订单：在 套餐页 填写同样的邮箱与 QQ 提交订单（需先登录）；
  3. 站主对账：站主人工对账，合理期限为 1～24 小时；
  4. 获取激活码：核实后激活码显示在 我的订单 页面，不另行邮件通知；
  5. 手动兑换：您在订单页输入激活码即可升级。

7.3 退款政策

付款金额用于覆盖上游 API 成本，一旦激活恕不退款。下单前请确认您需要会员特权。如遇下列情形之一可申请退款：（1）付款后未提交订单、未领取激活码；（2）本服务明显故障导致付费会员期不可用且超过订单期间的 50%。退款请通过本条款末尾的邮箱提交。

7.4 免费档、套餐与 API 的差异

免费档、个人套餐与开放 API 在计费方式、可用额度与速率限制上均存在差异。简要说明如下（详细数值请以站内文档实时所列为准）：

  • 免费档：可调用免费模型，并在共享池与每日个人额度内试用部分付费模型；受基础速率与并发限制，付费模型试用次数有限，高峰时段可能进入排队。
  • 个人套餐（Go / Plus / Pro）：Chat 网页与 Cancri Code IDE 共享同一月度额度池，全模型开放，按统一模型定价从套餐额度扣费；档位越高，月度额度越大、速率与并发上限越高，并享高峰优先路由等权益。
  • 开放 API：按预充值 ¥ 钱包余额实时扣费，速率与并发上限依据钱包限速档（Tier）确定，与套餐轨道相互独立。

提示：模型可用性与计费细节最终以服务端实时返回为准。具体错误码、额度折算与模型定价见 API 文档 与 模型广场。
