1. 适用范围

本《隐私政策》（以下简称“本政策”）适用于 NexusV（以下简称“本服务”或“我们”）通过网站、桌面客户端、开放 API 及相关功能向您提供的全部产品与服务。本政策与 《服务条款》 共同构成您使用本服务的基础规则。您使用本服务，即视为您已阅读、理解并同意本政策。

2. 定义

本政策中相关术语的含义如下：

  • 个人信息：以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。
  • 处理：包括个人信息的收集、存储、使用、加工、传输、提供、公开、删除等。
  • 第三方服务提供商：为我们提供模型能力、云计算、数据库、邮件通信、人机验证等服务的独立第三方。
  • 模型服务提供商：提供底层大语言模型或多模态生成能力的上游第三方。

3. 我们收集的信息

我们仅在为您提供服务所必需的范围内收集个人信息。

3.1 您主动提供的信息

  • 账户信息：邮箱地址。本服务使用邮箱一次性验证码完成注册与登录，不设置账户密码。
  • 支付对账信息：如您购买订阅或加油包，需在购买页面提交与支付备注一致的邮箱及 QQ 号，用于运营方人工核对款项与发放激活码。
  • 对话与生成内容：您在对话、图像生成、视频生成、文件分析等功能中输入的文本、图像、文件、提示词，以及您选择的模型、参数与设置。
  • 反馈与申诉信息：您主动提交的故障报告、功能建议、申诉材料、用户评价等。
  • 模型改进授权：您可在设置中选择是否允许将对话数据用于改进 Cancri 模型。新账户默认开启该选项，您可随时关闭。关闭后，历史对话仍会保存以供您查看，但会标记为不参与模型训练。

3.2 我们自动收集的信息

  • 设备与网络信息：IP 地址、User-Agent、浏览器类型、操作系统、屏幕分辨率、时区、语言偏好。
  • 使用记录：每次请求的模型标识、调用时间、token 消耗、计费金额（如适用）、会话元数据、接口响应状态等。
  • 客户端诊断信息：经您明确同意后，我们在未捕获的 JavaScript 异常发生时收集浏览器 UA、当前页面 URL、视口尺寸、异常消息与堆栈、最近 10 条 fetch 请求的 URL 与状态码（不含请求或响应正文）以及本机生成的匿名标识符，用于定位与修复客户端问题。如您选择不同意，我们不会采集上述信息。
  • 设备标识信息：您登录后，为识别同一设备下的多账号滥用行为，我们可能收集浏览器 Canvas、WebGL、Audio 指纹、WebRTC IP、字体、屏幕、时区、navigator 信息、硬件并发数、设备内存等指标，并生成一个不可逆的设备标识符。同一浏览器通常每 24 小时上报一次，失败静默，不影响业务使用。
  • 人机验证信息：登录及注册环节，我们可能要求您完成由 Cloudflare Turnstile 提供的人机验证。Turnstile 仅返回验证结果，不用于跨站广告追踪。

3.3 我们不收集的信息

我们不会主动收集以下信息：精确地理位置、通讯录、相册、麦克风、摄像头、生物识别信息、身份证号码、银行卡号、支付密码。本服务未接入任何第三方支付平台 SDK；付款由您通过微信或支付宝扫码直接完成，我们不接触您的支付凭证。

4. 信息的使用方式

我们仅在以下目的范围内处理您的个人信息：

  1. 完成账户注册、登录、身份验证与账户安全保护；
  2. 向您提供对话、文本生成、图像生成、视频生成、文件分析、开放 API 等核心服务，并将您的输入转发至您选定的模型服务提供商；
  3. 执行套餐额度、加油包、API 钱包的计费、配额管理与使用统计；
  4. 识别异常登录、刷量、自动化滥用、网络攻击，保障本服务与全体用户的安全；
  5. 进行去标识化、聚合化的服务统计、模型效果分析与产品改进；
  6. 在您授权范围内，将对话数据用于改进 Cancri 模型；如您关闭授权，新产生的对话仍会保存但标记为不参与训练；
  7. 处理您的订单、申诉、客服请求与运营通知；
  8. 遵守法律法规、监管要求或配合合法调查。

5. 委托处理与共享

5.1 模型服务提供商

为实现对话或生成服务，您的输入（文本、图像、文件、提示词等）将实时转发至您所选择的模型服务提供商。该等提供商有其独立的隐私政策与服务条款，本服务不对其处理行为承担直接责任。

5.2 基础设施与通信服务提供商

我们可能委托以下类别的第三方处理您的部分信息：

  • 云计算与边缘网络服务提供商（如 Cloudflare）：用于承载网关、流式响应、边缘计算与安全防护；
  • 托管数据库服务提供商（如 Aiven）：用于存储账户、会话、计费、使用记录等业务数据；
  • 电子邮件服务提供商（如 Resend）：用于向您发送验证码、通知与运营邮件；
  • 人机验证服务提供商（如 Cloudflare Turnstile）：用于登录环节的安全校验。

5.3 其他披露

除上述情形外，我们仅在以下情形披露您的个人信息：

  • 遵守适用的法律法规、法院命令、行政监管要求，或协助国家机关依法进行的调查；
  • 为保护本服务、用户或第三方的人身、财产安全或其他合法权益所必需；
  • 发生合并、收购、资产重组等情形，且受让方继续承担不低于本政策标准的个人信息保护义务。

除上述情形外，我们不会出售、出租或以其他方式向任何第三方提供您的个人信息。

6. 数据存储与安全

6.1 存储地点与期限

  • 账户信息：保存至您注销账户后，按法律法规要求的期限删除或匿名化；
  • 对话历史：保存于 PostgreSQL 数据库，您可在会话列表中删除单条会话；账户注销后按流程删除；
  • 使用与计费记录：保存期限不少于相关法律法规要求的最低期限；
  • 客户端诊断日志：在问题定位与修复后滚动清理，不长期留存；
  • 设备标识信息：在实现反滥用目的所需期限内保存，账户注销后解除关联；
  • 备份数据：按托管数据库服务商的滚动备份策略同步淘汰。

6.2 安全措施

我们采取以下措施保护您的信息安全：

  • 客户端与服务端通信使用 HTTPS（TLS 1.3）加密；
  • 身份鉴权采用签发的 JWT，访问后端接口需携带有效令牌；
  • 登录验证码单次有效且有时效，并设置请求频率限制；
  • 内部人员按最小权限原则访问数据，敏感操作留存审计记录；
  • 使用速率限制、异常检测、访问控制等手段防范自动化攻击与滥用。

互联网不存在绝对安全。如发生数据安全事件，我们将在确认影响后及时通过站点公告或注册邮箱通知受影响用户，并采取合理措施降低影响。

7. Cookie 与本地存储

本服务使用浏览器的 localStorage 与 sessionStorage 保存以下类别的信息：

  • 登录态：access / refresh token；
  • 偏好设置：主题、语言、界面状态、最近使用模型；
  • 同意与标识：遥测同意状态、匿名标识符、设备标识符、指纹上报节流标记；
  • 会话级临时信息：最近生成的 API Key（仅 sessionStorage，关闭标签页后自动清除）。

我们不在本地存储中保存聊天内容。我们不使用第三方追踪 Cookie，不参与跨站广告追踪。Cloudflare Turnstile 可能为维护验证会话设置其自有 Cookie，但不用于用户画像或广告推送。

8. 跨境数据传输

本服务依托 Cloudflare、Aiven 等全球化基础设施。您的数据可能在中国境外（如新加坡、美国、欧洲等）被存储或处理；当您选择由境外主体提供的模型服务时，您的输入将被实时传输至该服务所在地的服务器。使用本服务即表示您理解并同意上述必要的跨境数据传输。如您不接受跨境数据传输，请停止使用本服务并按第 10 条行使删除权。

9. 未成年人保护

本服务不面向未满 14 周岁的未成年人。如您未满 14 周岁，请勿注册账户。如您发现 14 周岁以下未成年人未经监护人同意使用本服务，请通过本政策底部联系方式告知，我们将在核实后删除相关账户及数据。14 周岁以上未满 18 周岁的用户，建议在监护人陪同下阅读本政策并由监护人同意。

10. 您的权利

对于您的个人信息，您享有以下权利：

  • 访问权：登录后通过会话列表查看您的对话历史；
  • 更正权：如需修改邮箱，请通过底部联系方式申请，经身份验证后处理；
  • 删除权：您可删除单条会话；也可申请注销账户，我们将在核实后删除或匿名化您的数据；
  • 复制/可携带权：可申请获取您的个人信息副本；
  • 撤回同意权：随时在设置中关闭模型改进授权，或清除遥测同意状态；
  • 投诉权：如认为我们违反本政策或相关法律法规，可向本服务或监管部门投诉。

行使上述权利通常不收费；如请求明显缺乏依据、过于重复或需要大量技术成本，我们可能拒绝处理或要求支付合理成本费用。

11. 政策更新

我们可能不时修订本政策。修订后的政策将在本页面发布，并以“最后更新”日期为准。涉及收集信息范围扩大、共享对象新增等影响您重大权益的变更，我们将通过站点公告、站内通知或注册邮箱提前 7 日告知。修订生效后继续使用本服务，即视为您接受修订后的政策。如您不同意修订，请停止使用本服务并按第 10 条行使删除权。
