卡密运营

收款走链动小铺： 用户在店里买卡 → 回站内「账单 → 兑换码」粘贴 → 自动到账。没有人工审核环节。

🔴 小铺没有任何 API，补货是纯人工的：下面「铸码」→ 弹出的明文整段复制 → 粘到小铺对应商品的库存里。卡密明文只在铸码那一次出现，库里只存 sha256， 关掉面板就再也拿不回来（丢了就把那批作废后重铸）。
🔴 粘错商品系统查不出来：没有平台回查这一层了，一张卡发什么货完全由我们库里 那一行决定。把 Pro 卡粘进 ¥1 商品，就是 ¥1 卖出一张 Pro，全程无报错。 卡号里的卡定位（如 CANCRI-PRO-…）就是给你粘贴前肉眼核对用的。

退款批量作废
小铺退款后用这里收回卡。到小铺后台把那笔订单发给买家的卡密复制过来， 整段粘进去即可（换行、逗号、空格分隔都认，混进别的文字会自动跳过）。
未兑现的直接作废；已兑现的只会挂进下面的人工队列——钱已经进了用户账户， 自动扣回会造成负余额，要不要追回由你判断。
⚠️ 小铺没有 API，系统不会自己发现退款。这一步不做，退款的卡就还能继续兑。
退款人工队列
这些卡已经兑现（钱/套餐已进用户账户），随后被你在上面「退款批量作废」里标记为退款。 自动扣回会造成负余额、而且额度可能已经花掉了，所以只打标记交人工裁决： 每行先选结论、填备注，再「记录结案」。
· 钱包卡：先到「用户管理」页做钱包调整（扣回金额），再回来记录结案；
· 套餐卡：绝不能用钱包扣款冒充撤销套餐——需人工调整套餐 / 限制账号 / 放弃追回，再记录结论；
⚠️ 本页「记录结案」只写处理结论，不自动改任何资金。
