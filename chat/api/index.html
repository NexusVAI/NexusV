开始使用 Cancri 进行构建

将 Cancri 集成到您的应用程序中所需的一切。从首次 API 调用到生产部署。

快速入门 获取 API 密钥 API 参考
Base URL https://chat.nexusvai.xyz/functions/v1/api-gateway 
# Cancri CLI 示例
cancri chat \
  --model gpt-5.4-mini \
  --max-tokens 1024 \
  --message '{ role: user, content: "Hello, Cancri" }'
# OpenAI 兼容协议
curl "https://chat.nexusvai.xyz/functions/v1/api-gateway/v1/chat/completions" \
  -H "Authorization: Bearer $CANCRI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.4-mini","messages":[{"role":"user","content":"Hello"}]}'
from openai import OpenAI

client = OpenAI(
    api_key="cancri_sk_...",
    base_url="https://chat.nexusvai.xyz/functions/v1/api-gateway/v1",
)
resp = client.chat.completions.create(
    model="gpt-5.4-mini",
    messages=[{"role": "user", "content": "Hello"}],
)
print(resp.choices[0].message.content)
01 — Protocols

三套原生协议，一把密钥。

不需要为不同模型提供商分别申请帐号、维护多份配额；一次申请，三处可用。

/v1/chat/completions
OpenAI 系
openai-python / openai-node SDK 直连可用，零代码改动。
/v1/messages
Anthropic 系
原生 Claude Messages 协议，支持 Claude Code 等官方工具链。
/v1/responses
Codex 系
兼容 OpenAI Codex CLI 的 responses 端点，支持工具调用与 reasoning。
02 — Quickstart

三十秒，跑起来。

把 base URL 换成 Cancri，import 不变。下面是最小可运行示例。 

# 兼容 OpenAI 协议
curl "https://chat.nexusvai.xyz/functions/v1/api-gateway/v1/chat/completions" \
  -H "Authorization: Bearer $CANCRI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4-mini",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
from openai import OpenAI

client = OpenAI(
    api_key="cancri_sk_...",
    base_url="https://chat.nexusvai.xyz/functions/v1/api-gateway/v1",
)

resp = client.chat.completions.create(
    model="gpt-5.4-mini",
    messages=[{"role": "user", "content": "Hello"}],
)
print(resp.choices[0].message.content)
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.CANCRI_KEY,
  baseURL: "https://chat.nexusvai.xyz/functions/v1/api-gateway/v1",
});

const resp = await client.chat.completions.create({
  model: "gpt-5.4-mini",
  messages: [{ role: "user", content: "Hello" }],
});
console.log(resp.choices[0].message.content);
