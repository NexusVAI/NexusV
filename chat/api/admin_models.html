倍率档位

每个模型costTier 归到一档，扣分 = token × 该档 factor。改一档会影响所有该档模垂 （Opus 等走 customMultiplier 的模型不受档位影响，单独压平。）

参考：free 让国产免费模型真便宜；normal 是主力付费档；vip Pro+ 可用的高价模垂 数值越大，同样 token 扣得越多

限时倍率促销

窗口内全站倍率统一乘以折扣系数（如 0.5 = 五折）。窗口外自动恢复 1.0
