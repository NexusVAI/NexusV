临时聊天

不包含在历史记录中

临时聊天不会出现在你的历史记录中。为了安全考虑，我们可能会保留对话记录最多30天。

不会用于模型训练

临时聊天不会被用来改进我们的模型。

记忆关闭

使用临时聊天时，Cancri 不会使用或更新记忆。系统仍然会遵循你的自定义指令。

创建项目
项目功能可将聊天、文件和自定义指令集中保存，以便用于持续进行的工作，或者单纯用于整理内容，让一切更井然有序。

  1. 07-24

    邀请功能上线

    我们推出了邀请功能，从今日起你可以邀请你的好友一起来用 Cancri！

    如何使用？

    • 点击左下角「头像」→「自定义」。
    • 进入页面后点击「邀请」，进入「邀请奖励」页面后自动显示邀请链接。
    • 发送给朋友注册即可。

    规则

    • 每邀请一位新用户，双方各得 1 元额度 *1。
    • 邀请的用户如果充值，返利 20% *2。

    *1 受限于平台风控机制检测，只有申请 API 通过后，并且累计 3 天有正常 Chat/API 流量后才会自动入账。

    *2 仅限首次充值，上限 100 额度。
