常见问题

现有 ¥9.9 用户会被影响吗？ 到期日完全不变。从今天起按 Pro 档位（月 2000 积分）计费，且 本订阅周期内继续可调 Claude Opus 全系（Phase A 老用户福利，Opus 权重照常生效，月度配额受 2000 积分限制）。 续费时根据用量自行选择档位（Pro 续费 / Pro+ 升级 / Pro Max 重度），续费后老用户福利失效，按所选新档位的明码规则计费。

为什么要分档？ 站开了几天烧了 10 亿+ token，订阅转化不足 10%，再不分档单位经济撑不下去。 Opus 系列上游成本是普通模型的几十倍，必须靠 Pro+ 档位的对等收入覆盖。这是为了能继续做下去，请各位理解。

加油包真的永不过期？ 是的。加油包余额独立于订阅档位，任何时候都能用，订阅过期后也能继续消耗。

可以一次买好几个月吗？ 可以叠加续费，但到期时间最长预付 90 天（从当前算起）。超出部分不会丢失，只是无法一次性囤积超过 90 天的会员时长。

没收到激活码？ 审核完成后激活码会显示在 我的订单 页面，不发邮件。

付款后没有立刻升级？ 这是人工对单的流程，付款 → 提交订单 → 站主对账 → 生成激活码 → 你手动兑换。请耐心等 1~24 小时。

付费后能退款吗？ 本服务所有费用用于覆盖上游 API 成本，一旦激活恕不退款。例外情形：（1）付款后未提交订单、未领取激活码；（2）服务明显故障导致付费期不可用且超过订单期间的 50%。退款请通过 GitHub Issues 或邮箱 nexusvai@139.com 提交。
