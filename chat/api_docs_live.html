实时语音：GPT-Live

gpt-live-1 是 OpenAI 官方的全双工实时语音模型：你持续推麦克风音频，它边听边说，同时给出双向转写。NexusVAI 用一条 WebSocket 接口把它开放出来，事件格式与 OpenAI Live 协议一致，只是 Base URL 和 API Key 换成我们的。

gpt-live-1 只负责「听和说」。需要思考、查资料、调工具时，它把任务委派给一个后端。你可以选三种后端之一：

模式怎么写谁来回答适合
官方后端（默认）不写 delegation，或 responses.model = "gpt-6-luna"OpenAI GPT-6-Luna，可开联网搜索与函数工具开箱即用的语音助手
站内模型responses.model 填 模型广场 里任意模型 id，例如 claude-haiku-5.5你选的站内模型（按它自己的价格计费）想要特定模型的口吻 / 能力
只买语音层delegation.type = "client"你自己的程序 / Agent已有 Agent，只缺语音外壳

一句话记住计费：语音按秒收（¥0.009/秒，即 ¥0.54/分钟），后端另算。官方后端按 Luna token 和联网次数收，站内模型按那个模型的价格收，只买语音层没有后端费。详见 计费。

当前不提供：WebRTC 接入（请用 WebSocket）、其它官方后端模型（gpt-6-sol / gpt-6-astra 等一律拒绝）、Fast/priority 档、Decisions 委派、会话存储与录音下载（store 只能为 false）、代码解释器 / shell / 生图等容器类工具。

连接与认证

GET

cn.nexusvai.xyz 加速地址暂不支持 WebSocket 升级，连上去会得到 426 websocket_required。实时语音请固定使用上面的 chat.nexusvai.xyz 地址。普通 HTTP 接口仍可继续用 cn.nexusvai.xyz。

API Key 放在哪

方式写法场景
请求头（推荐）Authorization: Bearer cancri_sk_...（或 x-api-key: cancri_sk_...）服务端：Node / Python / Go 等
WebSocket 子协议openai-insecure-api-key.cancri_sk_...（别名 cancri-key.cancri_sk_...）浏览器（浏览器的 WebSocket 不能自定义请求头）

用子协议传 Key 时，建议再附一个普通子协议（例如 cancri-live），服务端会选回这个普通子协议，Key 不会出现在响应头里：

new WebSocket(url, ["cancri-live", "openai-insecure-api-key." + key]);

别把正式 Key 写进公开网页。浏览器直连只适合本地调试。上线时请让浏览器连你自己的服务端，由服务端带 Key 转发；或者给前端单独发一把设了额度上限、只放行 gpt-live-1 的 Key（控制台 → API 密钥 → 模型白名单 / 累计额度）。

Key 的模型限制

  • Key 设了模型白名单时，白名单里必须有 gpt-live-1，否则握手返回 403 model_not_in_whitelist。用站内模型做后端时，那个模型也要在白名单里（后端调用走同一把 Key）。
  • Key 绑定了模型分组时，目前不能用于实时语音（403 model_not_in_group），请另开一把不绑分组的 Key。
  • Key 的累计 token / 请求次数上限已用完时，握手返回 429。

会话流程

  1. 建立 WebSocket。鉴权、封禁、限速都在握手阶段检查，不通过就直接返回 HTTP 错误（见 错误码）。
  2. 20 秒内发送第一条事件 session.start，超时会收到 session_start_timeout 并断开。
  3. 网关先预扣第一段（30 秒）语音费，再连上游。余额不足时收到 error（insufficient_balance）后断开，不产生费用。
  4. 收到 session.started 和 cancri.session.created 后，开始持续发送 session.input_audio.append。
  5. 结束时发 session.close，等 session.closed（里面有最终计费秒数）和 cancri.billing.updated（final: true）。

在 session.started 之前发来的事件会先排队，开始后按顺序转发，最多排 200 条。

快速开始

Node.js（服务端，npm i ws）

读一个 24 kHz、单声道、16 位的 PCM WAV 文件，按真实速度（每 100 ms 一块）推上去，打印转写，把回复音频存成文件：

import WebSocket from "ws";
import { readFileSync, writeFileSync } from "node:fs";

const URL = "wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions";
const ws = new WebSocket(URL, { headers: { Authorization: `Bearer ${process.env.CANCRI_API_KEY}` } });

const pcm = readFileSync("question.wav").subarray(44); // 跳过 44 字节 WAV 头
const out = [];

ws.on("open", () => {
  ws.send(JSON.stringify({
    type: "session.start",
    session: {
      model: "gpt-live-1",
      instructions: "你是一个简洁的中文语音助手。",
      audio: { format: { type: "audio/pcm", rate: 24000 }, output: { voice: "marin" } },
      // 不写 delegation = 默认官方 GPT-6-Luna 后端
    },
  }));
});

ws.on("message", async (buf) => {
  const e = JSON.parse(buf.toString());
  switch (e.type) {
    case "session.started": {
      for (let i = 0; i < pcm.length; i += 4800) {          // 4800 字节 = 100 ms
        ws.send(JSON.stringify({ type: "session.input_audio.append", audio: pcm.subarray(i, i + 4800).toString("base64") }));
        await new Promise((r) => setTimeout(r, 100));
      }
      setTimeout(() => ws.send(JSON.stringify({ type: "session.close" })), 15000);
      break;
    }
    case "session.output_audio.delta": out.push(Buffer.from(e.delta, "base64")); break;
    case "session.input_transcript.delta": process.stdout.write(`[你] ${e.delta}\n`); break;
    case "session.output_transcript.delta": process.stdout.write(`[AI] ${e.delta}\n`); break;
    case "cancri.billing.updated": if (e.final) console.log("本次费用 ¥", e.total_cny, "计费秒数", e.seconds); break;
    case "error": console.error("error", e.error); break;
  }
});

ws.on("close", (code, reason) => {
  writeFileSync("answer.pcm", Buffer.concat(out)); // 24 kHz / 16 位 / 单声道裸 PCM
  console.log("closed", code, reason.toString());
});

「静音」也是音频。真实对话里麦克风一直在推帧，所以模型能判断你什么时候说完；只推一段录音就停，模型可能一直等你继续说。示例里推完录音后不再发帧，靠 15 秒后的 session.close 收尾。

Python（服务端，pip install websockets）

import asyncio, base64, json, os, websockets

URL = "wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions"

async def main():
    headers = {"Authorization": f"Bearer {os.environ['CANCRI_API_KEY']}"}
    async with websockets.connect(URL, additional_headers=headers, max_size=None) as ws:
        await ws.send(json.dumps({
            "type": "session.start",
            "session": {
                "model": "gpt-live-1",
                "audio": {"format": {"type": "audio/pcm", "rate": 24000}},
                "delegation": {"type": "responses", "responses": {
                    "model": "gpt-6-luna",
                    "tools": [{"type": "web_search"}],
                }},
            },
        }))
        pcm = open("question.wav", "rb").read()[44:]
        async for raw in ws:
            e = json.loads(raw)
            if e["type"] == "session.started":
                async def pump():
                    for i in range(0, len(pcm), 4800):
                        await ws.send(json.dumps({"type": "session.input_audio.append",
                                                  "audio": base64.b64encode(pcm[i:i+4800]).decode()}))
                        await asyncio.sleep(0.1)
                    await asyncio.sleep(15)
                    await ws.send(json.dumps({"type": "session.close"}))
                asyncio.create_task(pump())
            elif e["type"].endswith("transcript.delta"):
                print(e["type"], e["delta"])
            elif e["type"] == "cancri.billing.updated" and e["final"]:
                print("费用 ¥", e["total_cny"])
            elif e["type"] == "error":
                print("error", e["error"])

asyncio.run(main())

websockets 14 以上用 additional_headers，老版本叫 extra_headers。

浏览器（麦克风 + 播放，仅限本地调试）

const KEY = "cancri_sk_...";   // ⚠ 只用于本地调试，见上方安全提示
const URL = "wss://chat.nexusvai.xyz/functions/v1/api-gateway/v1/live/sessions";
const ctx = new AudioContext({ sampleRate: 24000 });
let playAt = 0;

const ws = new WebSocket(URL, ["cancri-live", "openai-insecure-api-key." + KEY]);
ws.onopen = () => ws.send(JSON.stringify({
  type: "session.start",
  session: { model: "gpt-live-1", audio: { format: { type: "audio/pcm", rate: 24000 } } },
}));

ws.onmessage = async (ev) => {
  const e = JSON.parse(ev.data);
  if (e.type === "session.started") startMic();
  if (e.type === "session.output_audio.delta") play(e.delta);
  if (e.type === "error") console.error(e.error);
};

async function startMic() {
  const stream = await navigator.mediaDevices.getUserMedia({ audio: { channelCount: 1, echoCancellation: true } });
  const src = ctx.createMediaStreamSource(stream);
  const proc = ctx.createScriptProcessor(2048, 1, 1);   // 上下文已是 24 kHz，无需重采样
  proc.onaudioprocess = (ev) => {
    const f32 = ev.inputBuffer.getChannelData(0);
    const i16 = new Int16Array(f32.length);
    for (let i = 0; i < f32.length; i++) i16[i] = Math.max(-1, Math.min(1, f32[i])) * 0x7fff;
    if (ws.readyState === 1) ws.send(JSON.stringify({ type: "session.input_audio.append", audio: b64(i16.buffer) }));
  };
  src.connect(proc); proc.connect(ctx.destination);
}

function play(b64data) {
  const bytes = Uint8Array.from(atob(b64data), (c) => c.charCodeAt(0));
  const i16 = new Int16Array(bytes.buffer);
  const buf = ctx.createBuffer(1, i16.length, 24000);
  const ch = buf.getChannelData(0);
  for (let i = 0; i < i16.length; i++) ch[i] = i16[i] / 0x8000;
  const node = ctx.createBufferSource();
  node.buffer = buf; node.connect(ctx.destination);
  playAt = Math.max(playAt, ctx.currentTime); node.start(playAt); playAt += buf.duration;
}

function b64(ab) {
  let s = ""; const u8 = new Uint8Array(ab);
  for (let i = 0; i < u8.length; i += 0x8000) s += String.fromCharCode.apply(null, u8.subarray(i, i + 0x8000));
  return btoa(s);
}

浏览器需要用户先点一下页面才允许播放声音（可在点击时调用 ctx.resume()）。生产环境建议换成 AudioWorklet，并在用户打断时清空播放队列。

session.start 参数

第一条、且只能发一次。未列出的字段一律拒绝（unknown_parameter），不会静默忽略。

字段类型说明
session.modelstring只能是 gpt-live-1，可省略。
session.instructionsstring语音层的系统提示：语气、人设、语言等。≤ 64,000 字符。
session.audio.formatobject输入输出音频格式：{"type":"audio/pcm","rate":24000}（默认）或 rate: 16000；电话线路可用 audio/pcmu / audio/pcma，rate: 8000。PCM 为 16 位小端、单声道。
session.audio.output.voicestring音色名，例如 marin。可用音色以 OpenAI 官方 GPT-Live 文档为准。
session.inputarray预置对话历史，最多 128 条，每条 role 为 developer / user / assistant。
session.storefalse只能为 false 或省略。
session.triggers[]只能是空数组或省略（不提供 Decisions）。
session.delegationobject后端设置，见 三种后端模式。省略 = 官方 GPT-6-Luna。
session.delegation.acknowledgement_delay_msinteger委派开始后，过多久让语音层先说一句「好的，我查一下」之类的话。0–10000。
event_idstring可选，≤128 字符。出错时会在 error.client_event_id 里原样带回。

三种后端模式

① 官方后端：GPT-6-Luna（默认）

{
  "type": "session.start",
  "session": {
    "model": "gpt-live-1",
    "instructions": "你是旅行助手，回答简短。",
    "delegation": {
      "type": "responses",
      "responses": {
        "model": "gpt-6-luna",
        "instructions": "需要实时信息时先联网搜索。",
        "tools": [
          { "type": "web_search" },
          { "type": "function", "name": "get_order", "description": "查订单状态",
            "parameters": { "type": "object", "properties": { "order_id": { "type": "string" } }, "required": ["order_id"] } }
        ],
        "tool_choice": "auto",
        "reasoning": { "effort": "low" },
        "max_output_tokens": 2048
      }
    }
  }
}
delegation.responses.*说明
model只能是 gpt-6-luna（省略即此）。填其它 OpenAI 官方模型返回 live_backend_model_not_allowed；填站内模型 id 则进入站内模式（见 ②）。
instructions后端的系统提示，≤ 64,000 字符。
tools最多 32 个，类型只能是 web_search（按次计费）、function、custom（由你执行，无工具费）。其它类型返回 live_tool_not_allowed。
tool_choiceauto / none / required，或指向上面某个工具。
parallel_tool_callsboolean。
max_output_tokens16–128000。
reasoning.effortnone / low / medium / high / xhigh / max。越高越慢，输出 token 越多，费用越高。
service_tier只能是 default（不提供 Fast / priority）。
textobject，按 Responses API 原义透传。

会话中途修改后端：只有官方后端模式可以用 session.update，而且只能改 delegation.responses（同样受上表约束），其它字段（音色、格式、instructions 等）开始后都不能改。

{ "type": "session.update", "session": { "delegation": { "responses": { "reasoning": { "effort": "medium" } } } } }

函数工具：后端调用你的函数时，response.event 里会出现 function_call 输出项。你执行完把结果交回，再让它继续：

{ "type": "response.item.create", "item": { "type": "function_call_output", "call_id": "call_...", "output": "{\"status\":\"已发货\"}" } }
{ "type": "response.create" }

response.item.create 只接受 function_call_output / custom_tool_call_output 两种 item。

② 站内模型做后端

responses.model 填 GET /v1/models 列表里的任意 id，语音层仍是 gpt-live-1，思考交给你选的模型：

{
  "type": "session.start",
  "session": {
    "model": "gpt-live-1",
    "delegation": {
      "type": "responses",
      "responses": { "model": "claude-haiku-5.5", "instructions": "用中文一两句话回答。", "max_output_tokens": 512 }
    }
  }
}
  • 工作方式：语音层判断需要回答时发出委派，网关把到目前为止的双向转写（最近 60 轮、约 24,000 字符）整理成对话，用你这把 Key 调一次 /v1/chat/completions，再把答案交给语音层念出来。
  • 只接受 model / instructions / max_output_tokens（16–4096，默认 1024）。不支持工具，传 tools 等字段返回 live_site_backend_unsupported_parameter。需要联网请用官方后端。
  • 模型不在 /v1/models 里时，会话不会开始（live_backend_model_not_allowed），不收费。
  • 后端调用和普通 API 调用完全一样：按该模型价格计费，出现在用量记录里，受 Key 的白名单 / 额度约束。
  • 每次回答完成后你会收到 cancri.delegation.completed（含模型原文、耗时、token），方便显示或记录。
  • 后端看到的是语音识别出来的文字，可能有错字；同一时刻最多 2 个回答在途，再多时语音层会请用户稍等；单次回答 90 秒超时。
  • 站内模式不能用 session.update 改后端，也不能用 response.* 事件。

③ 只买语音层（自带 Agent）

{ "type": "session.start", "session": { "model": "gpt-live-1", "delegation": { "type": "client" } } }

语音层需要答案时会发：

{ "type": "session.delegation.created", "delegation": { "id": "item_9tA2bF3h7K9m2P5q8R1s4", "type": "delegation", "target": "client" } }

你根据转写（session.input_transcript.delta）自己算出答案，用同一个 delegation_id 交回：

{ "type": "session.commentary.append", "event_id": "result_1", "delegation_id": "item_9tA2bF3h7K9m2P5q8R1s4", "content": "订单今天已发货，明天送达。" }
  • session.commentary.append：要念出来的结果（语音层可能会转述）。
  • session.thinking.append：只给语音层看、不念出来的进度或事实；content 传 "" 可取消自动的「好的，我查一下」。
  • session.instructions.append 且 delegation_id: null：追加会话级指令。
  • 同一个委派可以多次追加；每条 content ≤ 8,000 字符（官方限制约 500 token，太长请分段）。追加成功会收到对应的 session.*.appended 确认。
  • 这三个 append 事件在官方后端与站内模式下也可以用，例如随时补充背景信息。

此模式只收语音费。

事件参考

所有事件都是 JSON 文本帧（不接受二进制帧）。网关对客户端事件做白名单检查：下表以外的类型、或带了不认识字段的事件，会在本地收到 error，不会发往上游，也不收费。

客户端 → 服务端

type字段说明
session.startsession第一条，见上文。
session.input_audio.appendaudio（base64）持续推麦克风音频。单条 base64 ≤ 2,000,000 字符，建议 20–100 ms 一块。
session.input_audio.mute / .unmute—暂停 / 恢复收音。
session.output_audio.fixture.playaudioOpenAI 协议原有事件，按官方文档原义转发（单条 base64 上限同上）。
session.commentary.append / session.thinking.append / session.instructions.appendcontent, delegation_id见 只买语音层。
session.updatesession.delegation.responses仅官方后端模式。
response.item.createitem仅官方后端模式，交回函数结果。
response.create—仅官方后端模式，让后端继续生成。
session.close—结束会话。服务端回 session.closed 后断开。

所有客户端事件都可以带 event_id（≤128 字符）。被拒绝时 error.client_event_id 会带回它，方便对应。

type说明

怎么扣钱

  • 按会话时长计费，不按说话时长。从 session.started 到会话结束，每一秒都计费，包括双方都沉默的时间。不用时请及时 session.close。
  • 分段预扣：开始前预扣 30 秒（¥0.27），快用完时再预扣下一段，结束后按实际秒数多退少补。余额连一段都不够时会话不会开始。
  • 秒数以上游为准：最终秒数取 session.closed.usage.seconds（向上取整）。异常断开、拿不到最终值时，取最后一次 usage.seconds 与网关计时中较大的一个。
  • 没开始不收费：鉴权失败、参数被拒、余额不足、上游连接失败等，在 session.started 之前结束的会话全额退回预扣。
  • 后端 token 按次结算：官方后端每完成一次回答（response.completed）按 usage 扣一次；联网按实际搜索次数扣。注意每轮回答都会带上此前的对话作为输入，长会话的输入 token 会逐轮变多。
  • 余额用完：续段预扣失败时收到 cancri.session.closing（reason: "insufficient_balance"，带 closes_in_seconds），已预付的时长用完后断开，WebSocket 关闭码 4402。

会话会被服务端结束的情况

reason触发条件
max_duration达到本档单会话最长时长。需要更长请在客户端自动重开会话（可用 session.input 带上历史）。
idle_timeout90 秒内没有任何转写、回复或非音频事件。只推静音不算活动。
insufficient_balance余额不足以续下一段（关闭码 4402）。
billing_unavailable计费服务暂时不可用，已预付时长用完时结束，防止产生未结算的费用。
upstream_closed / upstream_error上游 OpenAI 断开。按已用秒数结算。
start_timeout连接后 20 秒内没发 session.start。

平台更新时，进行中的会话可能被断开（按已用秒数结算）。建议客户端在非主动关闭时自动重连。

错误码

握手阶段（HTTP 响应，WebSocket 未建立）

浏览器的 WebSocket 拿不到握手失败的状态码与响应体，只会看到 onerror / 关闭码 1006。排查时请用服务端客户端或 curl 看具体原因。

HTTPcode原因
400live_webrtc_not_supported用了 POST（WebRTC 建会话方式），请改用 WebSocket。
426websocket_required不是 WebSocket 升级请求（或用了 cn.nexusvai.xyz）。
401invalid_api_keyKey 缺失、格式不对或已停用。
403account_suspended账户已被封禁。
403model_not_in_whitelist / model_not_in_groupKey 的模型限制不包含 gpt-live-1。
429key_token_quota_exhausted / key_request_quota_exhaustedKey 的累计额度已用完。
429live_rate_limited每分钟新建会话超过本档上限。
429live_concurrency_limit同时会话数达到本档上限。
503live_capacity_exhausted / service_unavailable / live_disabled平台繁忙或暂不可用，按 Retry-After 重试。

会话中（error 事件）

code是否断开原因
insufficient_balance是余额不足一段（30 秒）语音费，未收费。
session_start_timeout是20 秒内没收到 session.start。
invalid_request / invalid_json首条时是首条不是合法的 session.start，或事件不是 JSON 文本帧。
unknown_parameter / invalid_value首条时是字段不认识或取值不合法，param 指出具体字段。
model_not_found是session.model 不是 gpt-live-1。
live_backend_model_not_allowed首条时是后端模型不是 gpt-6-luna，也不在 /v1/models 里。
live_tool_not_allowed首条时是工具类型不在 web_search / function / custom 内。
live_service_tier_not_allowed首条时是service_tier 不是 default。
live_store_not_allowed / live_decisions_not_allowed首条时是不提供会话存储 / Decisions。
live_site_backend_unsupported_parameter是站内模型后端传了不支持的字段（如 tools）。
immutable_field_update否session.update 试图改不可改的字段，或非官方后端模式下改后端。
live_event_not_allowed / live_item_not_allowed否事件类型 / item 类型不受支持。
live_not_priced / quota_check_failed / live_upstream_unavailable是平台侧暂时不可用，未收费，稍后重试。

「否」表示只拒绝这一条事件，会话继续。上游 OpenAI 自己返回的 error 也按同样格式转发。

FAQ

  • 能直接用 OpenAI 官方 SDK 吗？事件格式一致，任何能连 WebSocket 并收发 JSON 的客户端都能用，把地址换成上面的端点、Key 换成 cancri_sk_ 即可。SDK 里写死的 WebRTC 流程不能用。
  • 模型一直不说话？确认你在持续推音频帧（包括静音），且格式与 audio.format 一致（默认 24 kHz、16 位、单声道 PCM）。
  • 怎么省钱？不说话时尽快 session.close；不需要联网就别开 web_search；reasoning.effort 用 none / low；纯语音外壳用「只买语音层」。
